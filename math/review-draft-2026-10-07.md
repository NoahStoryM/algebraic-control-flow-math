### 世界与记号速查

一个「世界」由箭头的类型与复合决定。带能力的宿主是想要的世界，纯宿主里造出来的是模拟它的世界。

| 世界 | 是什么 | 箭头 p → q 的类型 | 复合 | 数学上的读法 |
| --- | --- | --- | --- | --- |
| 𝒟 | 纯的宿主 | `p → q` | `∘` | 基范畴 |
| 𝒞 | 𝒟 加 `call/cc` | `p → q` | `∘` | 想要的世界 |
| 𝒦 | CPS 世界，模拟 𝒞 | `p → ¬¬q` | `∘𝒦` | 延续单子的 Kleisli 范畴 |
| 𝒰 | 逆否世界，𝒦 的另一种写法 | `¬q → ¬p` | 反向的 `∘` | 同一个范畴写在对偶一侧 |
| ℬ | 𝒟 加 `amb` | `p → q` | `∘` | 想要的世界，函数就是二元关系 |
| ℒ | 交出列表的函数，模拟 ℬ | `p → (Listof q)` | `∘ℒ`，即逐步 `append-map` | 列表单子的 Kleisli 范畴 |
| ℛ | 关系语言的世界（第五篇，未写） | 关系 `(P x y)` | `∘ᵒ`，用 `fresh` 与合取 | Rel 的一个实现 |

后文用到的几个名字：

| 名字 | 意思 |
| --- | --- |
| `¬a`，`⊥`，`⊥ᵃ`，`¬ₐ` | `(→ a ⊥)`；空类型；局部的答案类型 a；以 a 为答案类型的否定 |
| `cps:id`，`cps->neg²` | 延续世界的单位；连接器，把 `p → ¬¬q` 变成 `¬¬p → ¬¬q`，即 Kleisli 扩张 |
| 连接器，单位 | 系列对 Kleisli 扩张与 η 的叫法；列表世界里是「交给 `append-map`」与 `list` |
| `anf:let*`，`for*/list` | 各世界的绑定写法，写出来的就是那个世界的复合，多出来的只是中间结果的名字 |
| 局部延续，初始延续 | 到最近边界为止的剩余工作；边界处最先放入、最后执行的那个延续，平凡表示下是恒等 |
| `gather`，`scatter` | ℬ 与 ℒ 之间的搬运，即 reify 与 reflect |
| `choose` | `(shift k (append-map k p*))`，第五篇推导里的名字，`amb` 由它定义 |

## 数学背景

下面分八组列出系列依赖的论断，每条有编号，审阅时可以直接引用。这里用范畴论的词；第一部正文里不用。

### 第 1 组：延续（第一到四篇，已发表）

| 编号 | 论断 | 核对 |
| --- | --- | --- |
| 1.1 | ¬ = Hom(−, ⊥) : 𝒞 → 𝒞ᵒᵖ 与自己伴随，`flip` 是这个伴随的 Hom 集双射 Hom(p, ¬k) ≅ Hom(k, ¬p)。它给出延续单子 ¬¬；𝒦 是它的 Kleisli 范畴，𝒰 是同一个范畴写在对偶一侧的样子 | 推导 |
| 1.2 | `cps` 是单位 η（按「自然变换由它在态射上的作用定义」的约定，即 α(f) = α\_b ∘ F f）；`cps->neg²` 是 Kleisli 扩张；μ = `(cps->neg² values)` | 实测（外延相等） |
| 1.3 | 𝒞 ≅ 𝒦，经 `(∘ call/cc cps:f)`，需要 `call/cc` 并带前提；𝒰 ≅ 𝒦，经 `flip`，纯 | 第二篇正文 |
| 1.4 | Hom(−, ⊥) 的元素范畴是切片 𝒞/⊥：对象是一个具体的延续 (p, k : p → ⊥)，态射是满足 kq ∘ f = kp 的 f。切片的切片还是切片：(𝒞/⊥)/(p, k) ≅ 𝒞/p，这就是「栈的切片」，答案类型从 ⊥ 换成了 p | 推导，未查文献 |
| 1.5 | 延续 k : p → R 是 𝒞/R 的对象；恒等是终对象，⊥ → R 是始对象。正文的「初始延续」指的是前者，说的是构造与时间上最先 | 推导 |
| 1.6 | 按值调用的 CPS 最接近 Kuroda 的否定翻译，按名调用对应 Kolmogorov（Murthy 1990） | 凭记忆 |
| 1.7 | 答案类型可变时，eval(c) = c(id) : ((A → A) → B) → B，与 Atkey 的参数化单子一致 | 凭记忆 |
| 1.8 | A-翻译一节的来历：异常单子 E p = p + a；先否定翻译再 A-翻译得到 ((p + a) → a) → a；(p + a) → a 等价于一对函数 \[k, j\]，k : p → a 是当前局部延续，j : a → a 是初始局部延续；j 在一段局部计算里不变，平凡表示下是恒等，省掉以后剩 (p → a) → a；提前返回就是不调用 k | 推导；带两个延续的 CPS 印象中出自 Thielecke，凭记忆 |
| 1.9 | run e = λk. \[k, id\] e 是从异常单子 E 到延续单子 C p = (p → a) → a 的单子态射；A-翻译之后那一步是 run 的 Kleisli 扩张 `(cps->neg² run)` | 推导，草图实测；Astra 做过形式化 |

### 第 2 组：关系（第五篇）

| 编号 | 论断 | 核对 |
| --- | --- | --- |
| 2.1 | Kl(Powerset) ≅ Rel | 标准结论 |
| 2.2 | ℒ 是 Kl(List)。到 Rel 有「取支撑」的函子，保持复合，不忠实：列表多记了顺序与重数 | Astra 10/1 |
| 2.3 | 「带 `amb` 的宿主与 Kl(List) 等价」只在受限意义下成立：有限终止、无其他效应、延续可多次调用、按收集到的列表观察、一阶数据。正文说「同构」时已限定为纯的、有限的搜索 | Astra 10/1 |
| 2.4 | `gather` 与 `scatter` 是 Filinski 的 reify 与 reflect 在列表单子上的实例；`choose : (Listof a) → a` 与 `call/cc : ¬¬a → a` 同形 | Astra；文献凭记忆 |
| 2.5 | Rel 是 compact closed，Rel(X, Y) ≅ Rel(1, X × Y)，所以关系的元数只是「看成几组」。合取在环境的关系上是复合，析取是并；列表一侧析取是有序追加，复合只对一侧分配 | Astra 10/4 |
| 2.6 | 关系语言只用到 =、∧、∨、∃、⊤、⊥，没有否定与全称；在这一小块里经典逻辑与构造逻辑能证出的东西相同。对应的是「程序是公式，运行是找证明，答案是见证」，不是 Curry-Howard 那一支 | 创作者笔记，未核 |

| 3.1 | 用复合定义单子：给定对象上的映射 T，以及 p → T q 形状箭头上的复合 ⋆ 与单位 η，满足单位律、结合律，再加相容律 g ⋆ (η ∘ h) = g ∘ h，就得到 Kleisli 三元组，与单子等价。令 g\* = g ⋆ id，相容律给出 g ⋆ f = g\* ∘ f，再由另两条得到三条 Kleisli 律 | 推导（9/24） |

### 第 4 组：强度、可交换与求值顺序（第六篇）

### 第 5 组：定界延续与四变体（第三、七篇）

第三篇的化简规则：

```racket
(reset val) => val
(reset E[(shift k expr)])
  => (reset (let ([k (λ (v) (reset E[v]))]) expr))
;;    ^ 外层                    ^ 内层
```

| 编号 | 论断 | 核对 |
| --- | --- | --- |
| 5.1 | 两个 `reset` 各自的有无给出四种变体：外有内有是 `shift` / `reset`，外有内无是 `control` / `prompt`，外无内有是 `shift0` / `reset0`，外无内无是 `control0` / `prompt0` | 标准分类，凭记忆（印象中与 Dybvig、Peyton Jones、Sabry 的四分法一致） |
| 5.2 | 把栈写成帧的列表、边界写成列表里的 tag 条目，这两个有无就是两次决定：外层对应切开以后 tag 放不放回剩下的栈，内层对应捕获的那段拼回去时垫不垫一个新 tag。一刀两段，边界只有一个，两段各自决定留不留，所以两个决定独立 | Noah 提出，按规则核对 |
| 5.3 | 效应处理者对应外层无的两种。深处理者的规则是 handle E\[op v\] with h 变成 h 的分支作用于 v 与 λx. handle E\[x\] with h，分支在自己的边界之外运行、`k` 自带处理者，即 `shift0`；浅处理者的 `k` 不带处理者，即 `control0` | 由规则直接对出；文献（Forster 等 2017，Piróg 等 2019）凭记忆。注意：8 月的一次讨论里写的是「深处理者对应 `shift` / `reset`」，与这里不一致，请裁定 |

### 第 6 组：树、tag、处理者（第七篇）

| 编号 | 论断 | 核对 |
| --- | --- | --- |
| 6.1 | 三者是同一件事的三面。一次操作只做一件事：把（要的是什么，参数，到边界为止的剩余工作 k）递给边界。自由单子回答「递出去的是什么」，是树的一个节点；prompt-tag 回答「怎么送到」，是在有名字的边界处切栈；代数效应回答「谁来拆」，是边界上的处理者。栈上切下来的那一段就是节点里的 k | Claude 的分析 |

| 6.3 | 两族操作合在一起是 Free(F + G)，在代码里是两族结构体的并类型。只认识 F 的处理者把 G 的节点原样转交，得到 Free G 里的树。转交（树）与按 tag 直达（栈）是「越过不认识的边界」的两种做法 | 状态加选择的例子实测，两种写法结果相同 |

### 第 7 组：自由单子、列表与 Recof（第七篇结尾与第二部）

| 编号 | 论断 | 核对 |
| --- | --- | --- |
| 7.1 | Free F a = μX. a + F X。单位是叶子，扩张是嫁接（把每片叶子换成一棵树）。F-代数的范畴与 Free F 的 Eilenberg-Moore 代数的范畴等价 | 标准结论，凭记忆 |
| 7.2 | `(Treeof a) = (∪ a (Listof (Treeof a)))` 是 Free List，叶子带标号的玫瑰树。把第五篇 `choose` 里的 `append-map` 换成 `map`、边界处去掉 `list`，得到的就是它；拍平以后得回第五篇的列表 | 实测 |
| 7.3 | 拍平 Free List ⇒ List 是单子态射，由 List 自己的乘法作为 List-代数诱导。所以列表世界 ℒ 是树世界忘掉嵌套之后的样子 | 推导 |
| 7.4 | `(Recof a b) = (∪ b (Pair a (Recof a b)))` 是 Free(a × −) 在 b 处的值，同构于 List a × b，即日志单子（Writer），日志取 a 上的自由幺半群；b 取 `Null` 时就是 `(Listof a)`。这棵树每个节点只有一个孩子，只有一片叶子，嫁接就是 `append`。它是 Barr 与 Wells 14.2 节的 rec(A, B)；局部递归说的是 rec(A, B) ≅ A\* × B | typed/racket 下实测；书中的节号出自 6、7 月的讨论，未重新核对 |
| 7.5 | `Pair` 的两个位置都当孩子时，Free(X ↦ X × X) 是叶子带标号的二叉树，即带点对的 S 表达式；第四篇 `fib` 的递归树是这种形状 | 推导 |
| 7.6 | 列表单子（按元素类型算的那个，连接器是 `append-map`）不是任何自函子的自由单子。论证：自由单子里嫁接一个节点得到的还是节点，所以结果是叶子时原树必是叶子；而列表里两个元素的列表，一个送到空列表、一个送到单元素列表，接出来是单元素列表 | 推导，反例实测 |
| 7.7 | `Listof` 因此有三个身份，正文不能说混：当签名用（Free List 是 `Treeof`）；自己是一棵树（Free(a × −) 在 `Null` 处）；作为列表单子是树的商。第二种身份里单子的参数是叶子（列表的结尾），不是元素类型 | 推导 |
| 7.8 | 用结构体表示语法树时，签名必须是「一层」：孩子的位置留成类型参数，`(Exp x)` 是若干结构体的和，`(Ast a) = (∪ (Var a) (Exp (Ast a)))` 才是自由单子。直接递归定义的语法树是叶子类型为空的那一棵，即初始代数。带绑定的语言不在这套里 | typed/racket 下实测；绑定一句凭记忆 |
| 7.9 | Typed Racket 里的四处限制：`∪` 不带标签，叶子本身是列表或序对时与节点分不开；多态操作的返回类型藏在节点里，需要存在类型，语言没有；没有高阶类型，写不出「对任意签名的自由单子」，第一部只能一个签名造一棵树；用结构体继承表示和时，判断子类型以后类型参数会丢，写成并类型则过检查 | 实测 |

`Recof` 与 fold 拟用的写法（已定），接口照 rec(A, B) 的交换图，在 `typed/racket` 下过检查：

```racket
(struct (b) r0 ([b : b]))                 ; r0 : b → (Recof a b)             init
(struct (a v) r ([a : a] [v* : v]))       ; r  : a × (Recof a b) → (Recof a b)  cons
(define-type (Recof a b) (U (r0 b) (r a (Recof a b))))

;; f 由两条等式决定：
;;   (f (r0 b))   = (t0 b)
;;   (f (r a v*)) = (t a (f v*))
(: fold (∀ (a b x) (→ (→ b x) (→ a x x) (→ (Recof a b) x))))
(define ((fold t0 t) v)
  (define f (fold t0 t))
  (match v
    [(r0 b)   (t0 b)]
    [(r a v*) (t a (f v*))]))
```
