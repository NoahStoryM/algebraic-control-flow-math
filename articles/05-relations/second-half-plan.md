## 第 2 步：实现

要回答 09 结尾的两个问题：没有了绑定，`a`、`b`、`c` 是什么；一行 `(betweenᵒ l h a)` 交出什么。

- **未知项与环境**：名字是未知项，按身份区分；环境记着哪些未知项已经有值，就是 01 的字典。
- **目标**：一行关系交出一个目标。目标收到一个环境，交出零个或多个添了记录的环境，所以它是环境之间的二元关系，类型就是 ℬ 的箭头 `(→ℬ Env Env)`。
- **四样东西都是现成的**：合取是 `∘ℬ`，析取是 `amb`，成功是恒等，失败是 `(amb)`。07、08 讲的二元关系的复合在这里兑现。这是让实现变短的那一步。
- **两个抬升**：`function->relation` 与 `predicate->relation`；再加 `run*`，09 的程序就能运行。
- **两层要分清**：关系语言描述的是项之间的「关系」，实现它的是环境之间的「目标」。两种二元关系前后脚出现，正文里叫法不能混。
- **不引入合一**。所以条件的先后有讲究：未知项要先有值，后面的条件才读得到。
- 可选的一句：目标也可以写成 ℒ 的箭头 `(→ℒ Env Env)`，合取换成 `∘ℒ`，就不依赖 `amb`；两种写法之间是 `gather` 与 `scatter`。

代码文件的子模块 `rel-min` 里有一个暂定的内核，09 的程序在其中原样运行。写到这一步时要照正文的顺序重排，给目标加上类型：

```racket
(struct var ([name : Symbol]))                        ; 未知项，按身份区分
(define (value-of t s)                                ; 项现在的值；未知项还没有记录就报错
  (cond [(not (var? t)) t]
        [(dict-has-key? s t) (dict-ref s t)]
        [else (error 'value-of "~a 还没有确定" (var-name t))]))
(define (record x v s)                                ; 记下 x 是 v；已有记录或本身是值，就核对
  (cond [(not (var? x)) (check (equal? x v)) s]
        [(dict-has-key? s x) (check (equal? (dict-ref s x) v)) s]
        [else (dict-set s x v)]))
(define (((function->relation f) . t*) s)             ; 最后一个位置是结果
  (define-values (in* out*) (split-at-right t* 1))
  (record (car out*) (apply f (for/list ([t in*]) (value-of t s))) s))
(define (((predicate->relation p?) . t*) s)
  (check (apply p? (for/list ([t t*]) (value-of t s)))) s)
(define (conj . g*) (apply ∘ (reverse g*)))           ; 合取：目标的复合，写在前面的先运行
(define-syntax-rule (run* (x ...) g ...)
  (let ([x (var 'x)] ...)
    (in-amb (let ([s ((conj g ...) '())]) (list (value-of x s) ...)))))
```

## 第 3 步：关系语言的世界 ℛ

关系语言才是真正基于关系的世界，二元关系在这里定义最合适；`amb` 版与列表版都是对关系的模拟（Noah 10/5 18:35）。

- **复合**：07 用集合的语言写的定义里有「存在这样的 y」，在这门语言里就是 `fresh`，在表上是遮住中间一列：

```racket
(define-syntax-rule (fresh (x ...) g ...) (let ([x (var 'x)] ...) (conj g ...)))
(define (∘ᵒ Q P) (λ (x z) (fresh (y) (P x y) (Q y z))))   ; 原型里是变参的
```

- **四步搬过来**：07 的 `pick-a`、`pick-b`、`pick-c`、`check-right` 用 `function->relation` 搬到 ℛ，用 `∘ᵒ` 复合，得到关系版的直角三角形。
- **三个世界的交换图**：ℬ、ℒ、ℛ，对应第二篇 𝒞、𝒰、𝒦 的那张；搬运照 08 的样子带类型声明。配一个「注意」：没有合一，关系的方向是固定的；这门语言是建在 `amb` 上的。
- **回扣绑定的写法**（Noah 10/6 同意）：在 08 末尾两行的基础上添第三行 `(fresh (y) (P x y) (Q y z))  =  ((∘ᵒ Q P) x z)`。
- 原型里核对过：`function->relation` 保持复合与恒等；`∘ᵒ` 的单位是 `(function->relation values)`，一个有方向的相等；`relation->function` 能把关系搬回 ℬ。

## 第 4 步：与逻辑的对应

从 `∘ᵒ` 的定义引出（Noah 10/5 22:16）：集合写法里的「存在」对 `fresh`，「并且」对合取，「属于」对关系的应用。再补上另一半：

| 逻辑 | 表 | 实现 |
| --- | --- | --- |
| 存在 ∃ | 遮住一列 | `fresh` |
| 合取 ∧ | 两张表首尾相连 | `conj`，即 `∘ℬ` |
| 析取 ∨ | 两个子集取并集 | `disj`，即 `amb` |
| 真 ⊤ | 零元关系 `{()}` | `succeed`，即 `((predicate->relation (λ () #t)))` |
| 假 ⊥ | 零元关系 `{}` | `fail`，即 `((predicate->relation (λ () #f)))` |

- 两个单位兑现 02 的两个零元关系：`succeed` 是合取的单位，`fail` 是析取的单位。
- 认出这门语言：骨架是 miniKanren，差的只是合一。合一只在这里点一句（两头都可以有未知项的模式匹配），链接 ambKanren。完整的 miniKanren 不在这一篇实现。
- 表的样子参考 Noah 那篇知乎回答（附件里的 `refs/zhihu-answer-miniKanren.md`）。
