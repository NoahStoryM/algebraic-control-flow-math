## 三、数学背景的结论（10/4，Noah 提出，Astra 核对）

详细的在大纲「10/4 13:29」与「10/4 13:43」两节，原文在 `reviews/astra-art5-goal-relation-2026-10-04.md`。这里是一页的摘要。

**Noah 的认识**
- `(pythᵒ a b c)` 交出的**目标**（Goal）是二元关系，两头都是代换（变量环境）。`pythᵒ` 本身是从项到目标的函数。所以这门语言的程序是在描述变量环境之间的关系；`run`、`fresh` 创建新变量，`run` 最后从环境里读出变量。
- 两个库正是同一件事的两种写法：

  | | 类型 | 合取 | 析取 |
  |---|---|---|---|
  | miniKanren-typed（ℒ） | `Goal = Substitution → (Streamof Substitution)` | `bind` | `mplus` |
  | ambKanren `demo.rkt`（ℛ） | `Goal = Substitution → Substitution`，用 amb | `((conj g1 g2) s) = (g2 (g1 s))` | `((disj g1 g2) s) = ((amb g1 g2) s)` |

- 有了 amb，普通函数就可以看作二元关系，关系的复合就是普通的函数复合，这正是 `conj`。理想的二元关系用集合收答案，直接取并集；流有顺序，怎样合并（`mplus`、`mplusi`）对应不同的搜索策略。

**Astra 的限定（正文必须守住）**
- 分清三层：目标交出的**原始代换**、从代换读出的**查询答案**、答案表示的**数学解集**。「相同」「可交换」在三层上不是同一个断言。
- 可用的点题句：「在这个实现里，忽略结果的顺序和重复，一个目标可以看作代换之间的二元关系：它把一个输入代换关联到零个或多个成功的输出代换。」不说「这就是 miniKanren 的全部本质」。
- 「当且仅当」只对这里的三角形查询说；一般的查询可能交出带未知项的答案，一个答案代表一族值。
- amb 下「普通复合就是关系的复合」依赖 `collect` 的边界：`(collect (λ () (g2 (g1 s)))) = (append-map (λ (t) (collect (λ () (g2 t)))) (collect (λ () (g1 s))))`，限于纯、有限的搜索。使用 amb 的过程不再是数学上的函数。
- 合取在代换的关系上是复合，在解集上是交集。
- **「只增不改」推不出交换性**。能说的只是：纯关系式目标、搜索完整终止时，交换合取两侧不改变解集；原始代换和答案顺序可能不同。
- 04 的元组不是「小的环境」：元组会丢信息（`(l h)` → `(a h)` 丢了 l）。合一新增的是解释和维护信息的规则，不只是「换了两头的数据类型」。代换的键是变量的身份（`eq?`），不是名字。
- `bind` 与 `∘ℒ` 不是同一个函数。保留顺序和重复只对本文的 `choose` / `collect` 与有限列表成立。
- 两层的名字：那门语言描述的是项之间的 N 元**关系**；实现它的是代换之间的二元关系，正文叫**目标**。

**Claude 说错过的三处**（已向 Noah 说明，别再犯）：「只增不改所以只含 ≡ 的目标可交换」不成立；「07 只是确定两头的东西」说轻了；「04 的元组是小的环境」只是比喻。
