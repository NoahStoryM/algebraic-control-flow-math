## 三、后半大纲的说法（请逐条判断：成立 / 需要限定 / 不成立）

大纲全文见附件 `outline.md`（文章仓库 PR #145 的分支），后半从 4.2 起。

**A. 代换、目标与三层关系**

1. 一行关系交出一个目标；目标收到一个代换，交出零个或多个添了约束的代换；所以目标是 Subst × Subst 的子集，在 ℬ 里类型是 `(→ℬ Subst Subst)`。
2. 所有目标都是同一个积 Subst × Subst 的子集，所以合取是二元关系的复合（即 `∘ℬ`），析取是两个子集的并（在 ℬ 里就是 `amb`）；用户定义的关系参数个数各不相同，落到目标这一层才住在同一个积里，所以析取在这一层定义。
3. `succeed` 是恒等关系（对角线），合取的单位；`fail` 是空关系，析取的单位。
4. 关系有三层：用户定义的关系 `(→ Term ... Goal)` 描述项之间的关系；目标是代换之间的二元关系，实现上一层；代换本身。
5. 零元关系两层要分开：在语言这一层，`succeed`、`fail` 是不收任何项的关系，即零元关系 {()} 与 {}；落到实现，是目标这一层的恒等关系与空关系。

**B. 代换是什么（Noah 要定，请先给数学判断）**

6. Noah 的读法：代换是一张表，记着未知项之间要满足的关系（「环境表，表本身就是关系」）。
7. 另一种读法：一个代换是答案表的一行，有的列还没填；`run*` 收回来的全部代换才是整张表。

两种读法各在什么意义下成立？含未知项（未确定）的代换应当怎样看？

**C. 两个库与 ℬ、ℒ**

8. `demo.rkt` 的目标 `(→ Subst Subst)` 带 `amb`，是 ℬ 的箭头；`miniKanren-typed` 的目标 `(→ Subst (Streamof Subst))` 是 ℒ 的箭头（列表换成了流），合取是 `∘ℒ`。用 `amb` 还是用流实现回溯，就是 `gather` 与 `scatter` 两头的选择。（10/4 你对类似的说法给过限定，请对照这一版的措辞。）

**D. `run*` 与 ∃**

9. `run*` 不是关系，是转换：把目标用在空代换上，`in-amb` 收集（即 `gather`），只读出查询的那几列。只读几列，在表上是遮住其余的列，对上 ∃：`fresh` 引入的未知项不出现在答案里，就是被遮住的列。

**E. 合一**

10. 只用 `==` 写成的关系没有方向，可以倒着跑（如 `appendᵒ`）；由函数、谓词经 `function->relation`、`predicate->relation` 搬来的关系仍要求参数已知。
11. `==` 在表上是相等关系，即对角线。

**F. 关系的世界 ℛ（Noah 11/6 定保留）**

12. 关系语言才是真正基于关系的世界，二元关系在这里定义最合适；`amb` 版（ℬ）与列表版（ℒ）都是对关系的模拟。
13. ℛ 里的复合定义为 `(define (∘ᵒ Q P) (λ (x z) (fresh (y) (P x y) (Q y z))))`。集合写法里「存在这样的 y」就是 `fresh`，在表上就是遮住中间一列。
14. 前半的四步（`pick-a`、`pick-b`、`pick-c`、`check-right`，都是 ℬ 的箭头）用 `function->relation` 搬到 ℛ，用 `∘ᵒ` 接起来，得到同样的答案。`function->relation` 保持复合与恒等；`∘ᵒ` 的单位是 `(function->relation values)`。
15. ℬ、ℒ、ℛ 三个世界之间有一张交换图，对应第二章 𝒞、𝒰、𝒦 的那张。请判断：这张图上该有哪些箭头（搬运）、在什么意义下交换（原始代换、答案列表、解集）、ℛ 算不算一个范畴（结合律与单位律在哪一层成立）。

**G. 与逻辑的对应（第 7 节的对照表）**

| miniKanren | 逻辑 | 表（解集） |
| --- | --- | --- |
| `succeed` | ⊤ | 零元关系 {()} |
| `fail` | ⊥ | 零元关系 {} |
| `(== t1 t2)` | t1 ≡ t2 | 相等关系（对角线） |
| `(conde [g1] [g2])` | g1 ∨ g2 | 两个子集取并 |
| `(fresh () g1 g2)` | g1 ∧ g2 | 按共有的列拼接（没有共有的列时是笛卡尔积） |
| `(fresh (x) (P x))` | ∃x. P(x) | 遮住一列 |
| `(run* (x) (P x))` | {x ∣ P(x)} | 整张表 |

16. 这张表成立吗？表这一列是否就是关系代数（选择、投影、自然连接、并）的那一套，该不该这样认？
17. 「这就是 microKanren：用 `amb` 写，流的那一半由 ℬ 的复合与 `amb` 承担，差的是交错」是否准确？

18. Noah：以上都按数学上的集合理解；现实里容器不同，取并的方式不同，就对应不同的遍历顺序，会有死循环，不是本章重点。大纲把它放进结论的「未解的线索」：`amb` 深度优先，`(run 1 (q) (conde [(nevero)] [(== q 1)]))` 不停，流写法能交错。这样说准确吗？
