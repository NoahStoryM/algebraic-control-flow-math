`between` 写出来是个普通的函数，收到两个数，交出一个数。可是同一组输入，它交出的不止一个：

```racket
(in-amb (between 1 3))
;; =>
'(1 2 3)
```

把它记成一张表，`(1 3)` 这一组输入要占三行：这是一张关系的表。

（以下是从 03 挪来的原文。）

它是怎么算的？R 的条件是一整条链 l ≤ a ≤ b ≤ c ≤ h，循环却分了几步：一步选一条边，最后检查直角。

| 步骤 | 收到 | 对每个候选交出 |
| --- | --- | --- |
| 选 a | `(l h)` | `(a h)` |
| 选 b | `(a h)` | `(a b h)` |
| 选 c | `(a b h)` | `(a b c)` |
| 检查直角 | `(a b c)` | `(a b c)`，或者什么也不交出 |

每一步都把后面用得着的东西带上：a 选出来以后还要用，h 在选完 c 之前不能丢。每一步自己也是一个关系，收到的一项与它交出的每一项相关。两步接起来，`(l h)` 与 `(a b h)` 相关，是因为存在一个中间的 `(a h)`，让前后两步同时成立。这就是关系的**复合**（composition）：

```latex
Q \circ P = \{\, (x, z) \mid \exists y,\ (x, y) \in P \,\land\, (y, z) \in Q \,\}
```

把四步各写成一个交出列表的函数：

```racket
(define (pick-aᵒ t)
  (match-define (list l h) t)
  (for/list ([a (inclusive-range l h)]) (list a h)))

(define (pick-bᵒ t)
  (match-define (list a h) t)
  (for/list ([b (inclusive-range a h)]) (list a b h)))

(define (pick-cᵒ t)
  (match-define (list a b h) t)
  (for/list ([c (inclusive-range b h)]) (list a b c)))

(define (rightᵒ t)
  (if (apply pyth? t) (list t) '()))
```

用普通的 `∘` 接不上：`pick-aᵒ` 交出的是一整张列表，`pick-bᵒ` 只收其中一项。那就对列表里的每一项调用下一步：

```racket
(pick-aᵒ '(1 2))
;; =>
'((1 2) (2 2))

(map pick-bᵒ (pick-aᵒ '(1 2)))
;; =>
'(((1 1 2) (1 2 2)) ((2 2 2)))

(append-map pick-bᵒ (pick-aᵒ '(1 2)))
;; =>
'((1 1 2) (1 2 2) (2 2 2))
```

`map` 交出的是列表的列表，再下一步又接不上；`append-map` 把各项的结果接成一张，可以继续往下接。把这种接法记作 `∘ℒ`（ℒ 表示列表），从最右边的一步起，逐个用 `append-map` 接上：

```racket
(define ((∘ℒ . f*) x) (foldr append-map (list x) f*))

(define right-triangleᵒ (∘ℒ rightᵒ pick-cᵒ pick-bᵒ pick-aᵒ))

(right-triangleᵒ '(1 20))
;; =>
'((3 4 5) (5 12 13) (6 8 10) (8 15 17) (9 12 15) (12 16 20))
```

四步接起来，交出的正是第一节那张列表。前三步的复合就是那条链。链里的几个不等式在逻辑上是同时成立的，没有先后；是这个算法选了先 a、再 b、再 c 的顺序，去找满足它们的数。
