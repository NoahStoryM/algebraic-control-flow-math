## 一、数学核对

### 1. 7.4：四条规则

**【成立｜推导】** 固定一个底类型 A，记 Nₙ = ¬ⁿA，可以写成：

| 规则 | 层数形式 | 性质 |
|---|---|---|
| 矛盾律／否定消去 | Nₙ₊₁, Nₙ ⊢ ⊥ | 构造性 |
| DNI | Nₙ → Nₙ₊₂ | 构造性 |
| 排中律 | Nₙ ∨ Nₙ₊₁ | 经典逻辑中成立 |
| DNE | Nₙ₊₂ → Nₙ | 作为任意类型上的统一原则，需要经典逻辑 |

这里 A 可以代入复杂类型。代入 `Label` 也可以进行类型展开，但已不能继续把它当作一致逻辑中的普通命题。

**【有问题｜措辞】** “排中律凭空造出相邻的两支”容易读成同时交出两个值。应说：

> 不要求调用者事先提供其中任何一支，就能交出相邻两种类型之一。

`cc` 的首次返回和重入，属于操作语义，不是同时证明 p 与 ¬p。

**【有问题｜适用范围】** “DNE 减二，所以经典”必须限定为**任意 p 上的统一原则**。特殊实例可能构造性成立，8.2 正是这样的实例。自然演绎中，加入一般排中律或一般 DNE 都可得到经典逻辑；这两个原则的等价可对照 [Pfenning 的讲义 §2.2、练习 2.3](https://www.cs.cmu.edu/~fp/courses/atp/handouts/ch2-natded.pdf)。

### 2. 7.4、4、4.2：DNE 是否就是排中律加消支？

**【成立｜推导，但需补一步】** 给定 h : ¬¬p，对排中律作分类讨论：

- 得到 x : p，直接交出 x；
- 得到 k : ¬p，则 h(k) : ⊥，再由爆炸原理得到 p。

所以完整结构是：

> 排中律 + 分类讨论 + 矛盾律 + 爆炸原理。

用“先得到 p ∨ ⊥，再利用析取单位元消掉 ⊥”概括也成立，不过单位元这一步已经包含了从空分支消去的规则。**“唯一的经典成分来自排中律”是准确的。**

**【成立｜代码结构核对】** 第 4 节的实现可以这样认，但要明确是 **DNE 读法下**：

```racket
(if (list? v*)
    (apply values v*)
    (proc (λ vs (v* vs))))
```

把输入限制为 `proc : ¬¬p` 时：

- 结果分支解包并交回 p；
- 延续分支把包装后的 ¬p 交给 `proc`，这一调用具有结果类型 ⊥。

列表包装只是让两种运行情况可判别。

**【有问题｜不能省略的区别】** 原来允许 `proc` 正常返回 p 的版本，直接呈现的是 Clavius 律；那个 `else` 分支并不必然是一次产生 ⊥ 的调用。应在 4.2 把 `proc` 与包装后的函数分清以后，7.4 再回认“同一实现的 DNE 实例”。不要把两种读法直接混成一条。

### 3. 8.2：三重否定律

**【成立｜推导】** 纯 λ 项为：

```racket
(λ (kkkq)
  (λ (q)
    (kkkq (λ (kq) (kq q)))))
```

类型逐步是：

- `q : q`；
- `(λ (kq) (kq q)) : ¬¬q`；
- `kkkq : ¬¬¬q`，调用它得到 ⊥；
- 因而内层 λ 的类型是 ¬q。

整个类型就是 ¬¬¬q → ¬q。令 q = ¬ⁿA，得到 n+3 → n+1，对所有 n ≥ 0 成立。

**【有问题｜行为解释】** “程序要交出的结果本身是延续时，不必真的让 OS 来跑”说得太快。这段纯构造首先**返回一个等待 `q` 的函数**；等 `q` 交来，才调用 `kkkq`。它没有立即运行计算、取出原来那个结果。

建议说：

> 结果既然也是一个函数，就可以先把它交出去；等它收到 q，再用 q 构造所需的双重否定。

这也解释了为什么它能成立。

**【有问题｜行为等价与终止】** 有同样的类型，不等于可以在任意 Racket 上下文中替换专门化后的 `call/cc`。两者运行输入计算的时机可能不同。同样，“三重否定律是真定理，程序会结束”只能用于相应的全函数演算；若传入会循环或带控制作用的 Racket 函数，不能保证整个调用终止。

### 4. 7.4、8.1、8.4：相对层数与“第 0 层”

**【有问题｜本轮最需要修正的一处】** 下面两句话不能同时无条件使用：

1. 零点可以任意选，p 可以已经含有否定；
2. 落到第 0 层就必须捕获。

因为同一支三重否定箭头 ¬¬¬q → ¬q，以 q 为底是 3 → 1，以 p = ¬q 为底就是 2 → 0。**换一个记账零点，不会改变它是否构造性成立。**

我的建议是区分两个用途：

- **规则的相对性**：规则可以统一代入任意类型。
- **分类时的固定基准**：讨论整个否定塔时，固定一个尚未利用其内部结构的类型参数 A。

相应的准确结论是：

> 对任意底类型 A，目标层数至少为 1 的减二，都有统一的纯 λ 构造；最后的 ¬¬A → A 没有对所有 A 都适用的纯构造，但某些具体 A 可以。

**【有问题｜8.1 的反例】** “Byte 头上没有否定，所以其 DNE 要捕获”不能作为类型不可实现性的论证：

```racket
(λ (kkbyte) 0)
```

已经具有 ¬¬Byte → Byte 的类型。它当然没有运行程序、取回退出码。这说明你要解释的是**指定的运行行为**，不只是类型是否有居民。

8.1 可以保留：

> 要运行这段程序，并取得它实际交出的退出码，需要给它提供退出通道。

但不能由“Byte 没有否定”直接推出这一操作结论。

### 5. 8.3：Label 的否定塔

**【成立｜递归类型展开】** 在文中采用的递归类型等式 L = (L → ⊥) = ¬L 下，确实有 L = ¬ⁿL。因此“任意两个标签都可以作为函数与参数配合”成立。

**【建议｜措辞】** “任意两个标签都差一层”改成：

> 同一个标签类型既能放在参数的位置，也能放在它的否定的位置；层数已经不能区分这两个角色。

这里不是每个标签获得了一个无限大的整数层数，而是**无法给它分配与否定操作相容的有限层号**。“无穷否定塔”可以保留作展开的图像，“计数失效”比“计数免费”准确。

**【有问题｜类型相等不等于程序恒等】** “DNI、DNE 在它上面都是恒等”应改。只能推出它们的**源、目标类型都成为 Label**，恒等函数可以具有这些类型；不能推出既有操作就是恒等函数。例如标准 DNI 是：

```racket
(λ (l) (λ (k) (k l)))
```

这并不是通过展开类型就变成了 `(λ (l) l)`，更不能据此断言它们在带打印、跳转的环境中行为相同。

**【成立，但须限定｜一致性】** 把该递归等式当作普通命题等价，会破坏逻辑一致性。直接的见证是：

```racket
(define (d x) (x x)) ; d : Label
(d d)               ; : ⊥
```

后者不断自应用。准确说法是：这种递归类型允许纯 λ 项失去终止保证，因而“有类型的程序就是证明”的读法失效。**不是每次构造或使用 Label 都必定无限循环**；阴阳谜题的无限输出还要由它自己的调用结构解释。

**【有问题｜析取与联合】** 对真正带标签的和类型，L + L 仍保留左右标记，并不自动等于 L。这里的坍缩是使用普通联合，或明确遗忘分支标记后的结果。可以保留这一步，但不能称为保持全部信息的类型同构。

### 6. 开头说明、8.2：wait/fc 的一般类型

**【成立｜需区分版本】** 第一版“不正常返回”的实现可以一般化为 ¬p → ¬p。正文中的 ¬¬q → ¬¬q 是取 p = ¬q 的实例。这个类型本身由恒等函数即可实现，冻结上下文的特殊性确实不在这条逻辑公式里。

但允许 `proc` 正常返回的第二版，正文类型仍是 (¬q → q) → ¬¬q。它也有纯实现：

```racket
(λ (proc)
  (λ (kq)
    (kq (proc kq))))
```

所以**删除这条支线的数学理由站得住**，但建议写成“这两个接口本身都有普通纯函数实现”，不要把两版无说明地都归为 ¬p → ¬p。

### 7. 7.4：奇偶与“偶 ∨ 奇”

**【成立｜限定操作】** DNI、DNE 都保持层数奇偶。固定底类型、只使用这些加减二操作时，同奇偶的层号不能变为相邻层号。

**【成立｜推导】** 异奇偶的两个非负层号，把较低者反复 DNI，就能升到相差一层，然后函数调用。例如 0 与 3，先把 0 提升为 2。

**【有问题｜不要推广为所有配对的必要条件】** 这并不证明“同奇偶的类型永远不能配合”。具体类型的结构、其他可用函数、Label 的递归等式，都超出了这项记账。

**【成立，并可简化】** 从最底下的 p ∨ ¬p，得到任意 ¬²ⁱp ∨ ¬²ʲ⁺¹p（i,j ≥ 0），只需要在两支分别做 DNI，**不需要 DNE**。若从高处的排中律实例往下调，才可能遇到降层的问题。

但单向能得到这些析取，不意味着它们全部与原始排中律等强。例如 ¬p ∨ ¬¬p 是弱排中律。

### 8. 8.4：两类、三类、一类

**【成立｜以一般命题变量为基准】** 对一个没有额外假设的命题变量 p，按逻辑互推分类：

| 范围 | 否定塔的类别 |
|---|---|
| 经典逻辑 | 偶数层；奇数层 |
| 直觉主义逻辑 | 第 0 层；奇数层；从第 2 层开始的偶数层 |

DNI 与三重否定律给出后两类内部的互推。第 0 层与第 2 层一般不能合并。例如两世界 Kripke 模型：根世界尚不成立 p，唯一的后继世界成立 p；根世界成立 ¬¬p，却不成立 p。

**【有问题｜任意代入后不一定恰好三类】** 若代入 p = ¬q，第 0 层与第 2 层已经可由三重否定律合并。因而应说：

> 对一般的底命题，有这三类；具体代入后，类别可能进一步合并。

**【有问题｜Label 的位置】** Label 的“一类”应另列为递归类型等式下的坍缩，不能作为与经典、直觉主义并列的第三种一致逻辑。若真的在逻辑中允许该等式并推出矛盾，爆炸原理会使所有命题互推，不只是否定塔。

**【有问题｜结论范围】** “经典与直觉主义的全部差别，就是第 0 层并入偶数类”应缩为：

> 在这座否定塔上，两者的区别体现为第 0 层是否与其余偶数层合并。

一般 DNE 确实足以把直觉主义逻辑扩展为经典逻辑；但某个固定类型的 DNE，不能代表整个逻辑的经典化。

## 二、8 月旧素材的取舍

### 1. 7.4：“多一层的吃少一层的”

**【建议｜保留直觉，去掉必要性断言】**

可以写：

> 多一层的类型正是“接收少一层的值、结果为 ⊥”的函数类型。

“吃”可以偶尔作为口语，但正式解释用“接收”。“只有差一层才能配对”删除。层差三也能先用 DNI 构造适配，不能把“直接调用的接口条件”写成“所有构造的极限”。

第一篇留一个纯 λ 例子就够，最好直接服务于 8.2，不另摆三段高度相似的程序。

### 2. 7.4：“在手”视角

**【成立｜局部构造方法】** 若目标是 ¬ʲA，且 j ≥ 1，可以先写一个 λ，假设收到 ¬ʲ⁻¹A，然后设法产生 ⊥。

**【有问题｜原来的概括】** 这不是“目标那层被吃掉”，而是**用函数引入，把目标变成一个局部假设与函数体的任务**。那个参数也不是写 λ 时就实际拿到了，而是将来调用时才交来。

“手上的东西总是一奇一偶”只对某些构造成立。例如想造 Nᵢ → Nⱼ，展开目标后，两个假设的层数是 i 与 j−1；只有 i,j 同奇偶时，它们才异奇偶。可以拿来解释三重否定律，不能写成普遍规律。

### 3. 7.4、8.1：“配对只消耗，从不产出值”

**【有问题｜不宜原样使用】**

它混合了三个层次：

- 这次函数调用的结果类型是 ⊥；
- 整个 λ 构造可以返回一个函数值；
- 控制转移可能让其他上下文收到一个普通值。

建议收窄为：

> 这次调用不会向当前调用位置正常返回一个值。

“OS 在 ⊥ 那边接住”可以作形象说法，但要先说清：**程序把退出码交给通道，OS 接到的是退出码，不是一个 ⊥ 的值再变成退出码。**

此外，逻辑中有 `absurd : ⊥ → p`，所以“配对结果是 ⊥”本身也不是无法构造 p 的证明。

### 4. 第二篇 7.3：箭头的源、目标记账

**【有问题｜旧变换规则不正确】** 若统一把普通箭头 Nᵢ → Nⱼ 记为 (i,j)，正确变换是：

| 操作 | 层数变化 |
|---|---|
| cps | (i,j) ↦ (i,j+2) |
| neg | (i,j) ↦ (j+1,i+1) |
| flip | (i,j) ↦ (j−1,i+1)，要求 j ≥ 1 |

因为 `flip` 交换的是柯里化函数的**两个参数**，并不是普通箭头的源与目标。目标 Nⱼ = Nⱼ₋₁ → ⊥，它的参数层数是 j−1。

因此：

- `flip` 保持总层数，成立；
- `cps`、`neg` 增加总层数二，成立；
- **由总层数推出造不出 (2,0)，不成立**。目标总层数也是二，不变量没有排除它。

**【成立｜严格缩小构造范围后】** 如果限定为“从多态 `id` 出发，只连续应用这三个变换”，可以另作一个小证明：从 (0,0) 增至总层数二，只能先得到 (0,2) 或 (1,1)，`flip` 只在二者之间切换；再用 `cps`、`neg` 就超过二，无法降回。于是这套生成办法不能得到 (2,0)。

但这只证明**指定生成办法的局限**，不是所有纯 λ 项的不可能性证明。

**【建议】** 本轮不收入这段记账。它需要新增适用域和生成规则，而第一篇已经能把真正需要的区别讲清。“不能用这套操作生成”可以说，“第 0 层不可达”仍不应说。

## 三、叙事与篇内落脚点

### 1. 8.1 → 8.2 → 8.3 → 8.3.1：梯度与高潮

**【建议】** 我支持这个顺序，但将梯度理解为：

1. **运行**：双重否定是一段等待出口的计算；
2. **构造**：结果本身是函数时，可以直接写出消除的纯构造；
3. **失效边界**：递归类型让层号无法区分角色；
4. **解释程序**：把看似神秘的跳转拆成可追踪的函数调用。

它是认识逐步深入，**不是严格的“普通类型零层、否定类型一层、Label 无限层”分类定理**。

全篇高潮仍应落在 **8.3.1“用函数重写”**：读者看见多出来的星号记在闭包链里，并亲手把捕获改成显式函数。层数为这段提供入口，不应抢走它的解释工作。

8.2 的短 λ 构造是一个适合停顿的小高潮：刚认出的经典定律，代入后竟能直接写出来。

### 2. 篇内切分

**【建议｜首选三小篇】**

| 小篇 | 范围 | 切点前读者拿到的完整成果 |
|---|---|---|
| 第一小篇 | 0–6 | 从标签构造 cc、call/cc，完成 mul 的逐次简化，并看懂反向定义 |
| 第二小篇 | 7–8.2 | 认出经典成分，理解程序的双重否定接口，并亲手构造三重否定消除 |
| 第三小篇 | 8.3–9.1 | 看清 Label 的特殊性，解开阴阳谜题，得到 CPS 的具体实例 |

切在 **6 之后、8.2 之后**。

第二个切点尤其合适：此时“减二是否总要捕获”已经得到一个明确的否定答案和完整程序。第三小篇再换到 Label，有充分理由重新起步。

若只分两小篇，我会选 6 之后；但后半仍同时承担逻辑、层数与谜题，缓解疲劳的效果较弱。

**【有问题｜8.2 的数学措辞】** 弱排中律若保留，不宜只写“仍是经典的”。更准确的是“经典逻辑中成立，直觉主义中一般不能证明”。它并不等同于完整排中律；相关研究把它单独作为中间逻辑原则处理，参见 [The Algebraic Significance of Weak Excluded Middle Laws](https://arxiv.org/abs/2108.09168)。

**【建议｜8.4 的位置】** 我不赞成在阴阳谜题结束后，再展开一个完整的分类定理。那里读者刚获得全篇最强的具体解释，再切回分类容易削弱收尾。若 Noah 希望严格维持当前次序，8.4 最好只留短回扣，不新增证明义务。

## 四、第二篇的连带影响

### 1. 第二篇 7.3：迁走以后还剩什么？

**【成立｜仍有独立内容，但不必独立成节】** 第一篇迁走的是：

- 层数与 `k` 的基础约定；
- DNI、相邻调用；
- 三重否定律的构造与命名；
- 一般 DNE 与特殊实例的区别。

第二篇真正新增的内容仍有：

1. 第一篇的 DNI 在这里就是 `cps:id`；
2. 第一篇的三重否定构造在这里就是 `(neg cps:id)`；
3. 7.2 的运行等式，怎样表现为把计算交给延续：

```racket
(kp (call/cc kkp)) ≈ (kkp kp)
```

**【建议】** 将 7.3 压成一段桥接，或并入 7.4 开头，不再重讲整座否定塔。旧的源、目标不可能性记账也不必填进这个空位。

顺带要区分两个等式：`kkp = (cps:id p)` 时，`(kkp kp) = (kp p)` 是直接 β 化简；面对任意 `kkp`，利用 `call/cc` 的那条则依赖 7.2 已说明的控制语义条件。

### 2. 第二篇 7.4：主旨会不会被第一篇提前讲掉？

**【成立｜不会】** 7.4 的问题与第一篇不同：

- 第一篇：**把类型代入 DNE，哪些实例能直接构造？**
- 第二篇：**同一支宿主 DNE 箭头，换一种表示后是什么？**

因此下面这组对应仍然是第二篇独有的推进：

| 表示 | 展开后的层数 |
|---|---|
| 宿主 DNE | 2 → 0 |
| CPS 表示 | 2 → 2 |
| 逆否表示 | 1 → 3 |
| 再否定后的纯表示，第二篇 8.2 | 4 → 2 |

第一篇讲过三重否定律，反而让读者在最后一行有东西可认，不必同时学习新定理和新表示。

**【建议】** 7.4 开头保留大纲现有的具体问题：

> cps:call/cc 不是 (cps call/cc)，那么后者是什么？

这个问题足以驱动整节。短回指层数以后，马上进入两种展开，不需要另一节完整的“数一数 k”。

### 3. 第二篇 7.4、8.2：仍须守住的边界

**【建议】** 保留并突出两件事：

- `(cps call/cc)` 的原始代码仍调用 `call/cc`；得到纯代表，依赖已经论证过的行为等式，不是看类型就能删除控制操作。
- 2 → 2、1 → 3、4 → 2 是**接口改变后的表示**；取回原类型的结果，仍涉及运行边界。

这样，第一篇交给读者的是构造三重否定消除的办法，第二篇回答的是为什么经典操作经过改写会落到这类纯构造上。两篇各自有完整收获，衔接也不会断。
