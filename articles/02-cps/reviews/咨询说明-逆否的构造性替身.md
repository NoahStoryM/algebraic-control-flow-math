# 咨询说明：`neg` 为什么还能从 𝒰 落回 𝒟（2026-10-16）

Noah 想听 Astra、Argon、新对话 Opus 对一个新想法的看法。下文的行号对应文章仓库 `dev` 的 `b7a6ec7`，文件 `zh/02-cps/article.md`。

## 一、问题

第二篇最难讲的一处，是四世界图里 `neg` 的第二种读法：它把 𝒰 的箭头 $¬q → ¬p$ 送到 $¬¬p →_𝒟 ¬¬q$（第 507 行）。只要这条边有了动机，双重否定 `neg²` = 𝒟 → 𝒰 → 𝒟，以及从 𝒦 回到 𝒟 的 `(∘ neg flip)` = 𝒦 → 𝒰 → 𝒟，都能从图上直接读出来。

现在的「落回 𝒟」（第 458 行起）是这样引出这条边的：先把宿主分成 𝒞 与 𝒟，再问 𝒰 的箭头能不能直接算 𝒟 的箭头，接着发现两端对调了，于是引入 `←`、`⨾`，再用一次 `neg` 把方向翻正。几轮读者都说这里动机不足，因为「方向对调」是作者检查结构时才会问的问题。

10/16 三份独立评审的对照见 #33 的评论。三家都同意把 `(∘ neg flip)` 写进正文，认作宏里每个绑定在做的事，但对它放在宏之前还是之后有分歧。Noah 补充的数学背景见账本 1.10：¬ 与自己伴随，`neg` 加 `flip`（Hom 集双射）与 `neg` 加 `cps`（单位）是两种等价的给法，`neg`、`flip` 两两复合给出 J、Kleisli 扩张与单子 T。正文第一部不用这些术语。

## 二、想法（Claude 10/16）

动机不从「方向反了」里找，而从「经典与构造」一节已经铺好的地方接。那一节第 375 行说：从 𝒰 回 𝒞 是 $(¬q → ¬p) → (p → q)$，「逆否律的逆方向，同样是经典定理」，所以 `unneg` 要用 `call/cc`。读者读到这里，接下来自然会问：

> 不许用经典定理，手里只有 $¬q → ¬p$，构造性地能推出什么？

答案是再取一次逆否：$(¬q → ¬p) → (¬¬p → ¬¬q)$。它是逆否律本身，直觉主义成立，代码就是 `neg`。所以 `neg` 第二次出场，是「逆否律的逆」的构造性替身：推不出原命题 $p → q$，只能推出两端各套一层 $¬¬$ 的 $¬¬p → ¬¬q$。落地的节点是 $¬¬p$，正是拆不掉 $¬¬$ 的代价。

𝒦 也问同一个问题：回 𝒞 是 $(p → ¬¬q) → (p → q)$，即 DNE，经典；构造性的替身是 $(p → ¬¬q) → (¬¬p → ¬¬q)$，代码是 `(∘ neg flip)`。

由此带来的几处改动：

1. **出场位置**：第二种读法与 `unneg` 并排，放进「经典与构造」。从 𝒰、𝒦 出去各有两个出口：经典的回到 𝒞（要 `call/cc`），构造性的回到 𝒟，两端套上 $¬¬$。
2. **图**：每个世界画经典、构造两条出边，𝒟 一侧的节点写成两端带 $¬¬$。`neg²` 与落回都是图上的路径。
3. **否定翻译的落点**：经典的 $p → q$ 变成构造性的 $¬¬p → ¬¬q$，是否定翻译在单个箭头上的样子。背后是 Glivenko 一类结果：命题逻辑里，经典可证的命题加上 $¬¬$ 后构造性可证；直觉主义里 $¬¬(p → q)$ 与 $¬¬p → ¬¬q$ 等价（Claude 凭记忆，未核原文）。
4. **`←`、`⨾`**：不再承担动机，只说明 `∘𝒰` 里那个 `reverse` 的来历，或者挪到别处。

要写明的前提：这条构造性的边只对用 lambda 写成的 𝒰 箭头成立。𝒰 的箭头内部若调用了宿主的 `call/cc`，套上 `neg` 仍然在调用。这与 `neg²` 签名改为 𝒟 → 𝒟 是同一件事。逻辑读法下前提自动成立（证明里没有经典规则），程序读法下要用一句话说明。
