# 第二篇试验：用宿主的 `let*` 与 `neg²:` 重写「嵌入语言」的例子（2026-10-16）

Noah 10/16 要的试验：把第二篇「嵌入语言」的几个例子改用宿主 `let*` 与 `neg²:` 箭头写，看代码和运行行为，供他想叙事。只是材料，不是正文稿。

代码与全部运行结果：`articles/02-cps/checks/d-side-rewrite-1016.rkt`（依赖同级目录下的文章仓库，底本 `dev`；Racket 8.10，全部 check 通过）。

## 工具

分两档，看各自能写到哪里。

- **第一档**：只用 `neg²`（把纯函数搬成 ¬¬p → ¬¬q）、`cps:id`、Noah 的 `neg²:call/cc`，加宿主的 `let*`。
- **第二档**：再加「落回」`(neg (flip h))`，把一支 𝒦 箭头 h : p → ¬¬q 变成 ¬¬p → ¬¬q。按旧的命名约定，h 落回以后记作 `neg²:h`；对纯函数 f，`neg²:f` 就是 `(neg² f)`（实测）。

```racket
(define (落回 h) (neg (flip h)))

;; Noah 10/16 的定义；类型里 proc 的返回改成 ¬¬a
;; (: neg²:call/cc (∀ (a) (→ (¬¬ (→ (¬¬ (→ (¬¬ a) (¬¬ ⊥))) (¬¬ a))) (¬¬ a))))
(define ((neg²:call/cc kkneg²:proc) ka)
  (kkneg²:proc (λ (neg²:proc) ((neg²:proc (cps:id (neg² ka))) ka))))
```

## 结果一览

| 例子 | 第一档 | 第二档 |
| --- | --- | --- |
| (1 + 2) × 3 | 能写，得 9 | 不需要 |
| `mul` 遇零跳出 | 正常路径能写；跳出那一步多出一层 ¬¬，运行时报错 | 能写，结果与原文一致；跳出时后面的乘法没有执行 |
| 阴阳谜题 | 写不出：连「先运行这段、再运行那段」都做不到 | 能写，输出前缀与原文一致；每个结果的名字只能在 λ 里起 |
| 名字用两次 | 运行两次（`"!!"`） | （`anf:let*` 只运行一次，`"!"`） |

## 例一：(1 + 2) × 3

```racket
(let* ([kkv ((neg² +) (cps:id 1 2))]
       [kkw ((neg² (λ (v) (* v 3))) kkv)])
  kkw)
```

结果 9，与原文一致。`let*` 绑定的 `kkv`、`kkw` 是编码好的计算，不是数；`3` 只能写进纯函数里，`v` 这个名字也只能在 λ 里起。

## 例二：`mul`，遇零跳出

列表留在宿主里，分支用宿主的 `if`，正常路径的乘法用 `neg²`：

```racket
(neg²:call/cc
 (cps:id
  (λ (kkesc)                                   ; kkesc : ¬¬(¬¬a → ¬¬⊥)
    (let loop ([r* r*])
      (cond [(null? r*) (cps:id 1)]
            [(zero? (car r*))
             (define (g esc) ((neg² absurd) (esc (cps:id 0))))   ; g : (¬¬a → ¬¬⊥) → ¬¬a
             ((落回 g) kkesc)]                  ; 第一档写成 ((neg² g) kkesc)
            [else
             (define r (car r*))
             ((neg² (λ (res) (* res r))) (loop (cdr r*)))])))))
```

- **第一档**：跳出那一步要用 `kkesc` 里面的 `esc`。`g` 收到 `esc` 交出 ¬¬a，它本身是一支 𝒦 箭头；用 `neg²` 搬它，得到 ¬¬¬¬a，多一层。运行时这多出来的一层被当作数交给了乘法：`*: contract violation, expected: number?, given: #<procedure>`。
- **第二档**：把 `(neg² g)` 换成 `(落回 g)`，多的那层就没有了。`'(1 2 0 3 4)`、`'(1 2 3 4)`、`'()` 三个输入，结果与原文一致（0、24、1）。在乘法里打印：遇零时什么都没打印，不遇零时打印 `*3 *2 *1`，即跳出时后面的乘法确实没有执行。

## 例三：阴阳谜题

- **只用 `neg²` 写不出。** `neg²` 只能改一段计算的结果，做不到「先运行这一段，再运行那一段」，更做不到让后一段依赖前一段的结果。
- **照字面用宿主 `let*` 给四段计算起名字**（`kkyin`、`kk@`、`kkyang`、`kk*`），先后靠落回接，最后那一步 `(cps:yin cps:yang)` 要的是两段计算的结果，写不出来，只能丢掉。输出 `"@*done"`：四段各跑一次，没有阶梯。
- **第二档**：每一步用落回接，结果的名字在 λ 里起：

  ```racket
  ((落回 (λ (cps:yin)
           ((落回 (λ (_)
                    ((落回 (λ (cps:yang)
                             ((落回 (λ (_) (cps:yin cps:yang)))
                              (cps:display #\*))))
                     (cps:label))))
            (cps:display #\@))))
   (cps:label))
  ```

  输出前缀 `@*@**@***@****@*****@` 与原文一致。这正是 `anf:let*` 展开后的样子：一个绑定就是一次「落回作用在函数体的 λ 上」。

## 附：名字用两次

```racket
(anf:let* ([v (cps:say1)]) (cps:+ v v))                  ; 打印 "!"
(let* ([kkv (cps:say1)]) ((neg² +) (pair2 kkv kkv)))     ; 打印 "!!"
```

`cps:say1` 打印一个 `!` 再交出 1。`anf:let*` 绑定的是结果，`say1` 只运行一次；宿主 `let*` 绑定的是计算，用两次就运行两次。

## 读出来的东西（Claude 的观察，供 Noah 想叙事）

1. 第一档（`neg²` 加宿主 `let*`）能做的，只有「改一段计算的结果」：纯函数一路搬下去。一旦后一步要做的事取决于前一步的结果（跳出、分支、阴阳谜题），就多出一层 ¬¬，宿主的 `∘` 和 `let*` 压不回去。
2. 压回去的办法是落回，它就是 `anf:let*` 每个绑定在做的事。所以「不用新语法、留在宿主」走到底，得到的就是手写的 `anf:let*` 展开式。
3. Noah 的 `neg²:call/cc` 在第二档里可以正常使用，行为与 `cps:call/cc` 一致。它的类型是 Clavius 律的 Kolmogorov 翻译（外面少一层 ¬¬）。
4. 落回与 `neg²` 的关系：对纯函数，落回 `(cps f)` 就是 `(neg² f)`；先在 𝒦 里接再落回，等于先落回再用 `∘` 接（都已实测）。
