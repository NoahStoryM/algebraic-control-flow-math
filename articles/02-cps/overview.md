## 各节讲什么

标着「10/6」的是这次修订新增或改写的内容。

| 节 | 讲什么 |
| --- | --- |
| 求值顺序与 ANF | `fact`、`fib` 写成 `let*`，求值顺序显式；`let` 脱糖为 λ 调用，认出延续 |
| 延续与 CPS | `fact/k`、`fib/k`：所有调用都成了尾调用，栈上的增长搬到了堆上的闭包链；尾递归版复用同一个 `k` |
| 　初始延续 | `a->⊥` 用 `raise` 抛出答案，`⊥->a` 接住 |
| 　一等控制 | CPS 版的 `mul` 遇零短路：选择调用哪一条延续就是选择控制流。留下抱怨：每个延续都要亲手写 |
| 否定的层次 | 柯里化把延续参数分出来，得到 `neg` 与 `cps`，类型是逆否律与双重否定引入；`flip` 在两者之间来回。10/6：`neg` 接两次的化简；`fact/k` 的闭包链就是 `(∘ k mul3 mul2 mul1)` |
| 　三种箭头 | 世界 𝒞、𝒦、𝒰；`∘𝒰`；`∘𝒦` 绕道 𝒰 定义。10/6：把 `∘𝒦` 展开，得到 `((cps:f x) (λ (y) ((cps:g y) k)))`，正是手写 CPS 时的包法 |
| 经典与构造 | `uncps` 借 `call/cc` 回到 𝒞；两个方向都是恒等；三个世界的交换图；`unneg`；注意框给出同构的两个前提 |
| 　两个 call/cc | `cps:call/cc` 与 `neg:call/cc` 只用 λ 与函数应用 |
| 　否定翻译 | 纯宿主 𝒟 与 `inj`；𝒰 的两端对调，引入 `←`；`neg¹`、`neg²`、`cps->neg²`；四个世界的图。10/6：换一个方向化简，得到 `(∘𝒦 cps:g cps:f)  =  (∘ neg²:g cps:f)` |
| 再次隐藏延续 | 10/6 重写：`anf:let*` 与 `let` 的脱糖并排，只多一个 `cps->neg²`；两段化简落到「`let*` 是 `∘` 的另一种写法，`anf:let*` 是 `∘𝒦` 的另一种写法」。然后是宏与 `anf:eval` |
| 嵌入语言 | `cps:` 提升的基本操作；用嵌入语言重写 `mul` 与阴阳谜题 |
| 　计算的位置 | 10/6 改短：每个绑定处有一个具体的延续；相邻两处只差一步，`kp  =  ((neg f) kq)  =  (∘ kq f)`；执行就是从一个延续走到下一个 |
| 结论与未解的线索 | 编码不需要 `call/cc`，可 `¬¬a` 不是 `a`：启动它需要一个 `¬a` 的元素，`a->⊥` 是从宿主借来的。`⊥` 到底是什么？ |
| 完整代码参考 | 全文的定义，可直接运行 |
