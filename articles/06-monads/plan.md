## 一、主线

**一句话**（v1.3，按 Noah 10/7 口述）：从程序员最熟悉的赋值进入，问纯函数怎样模拟赋值：把状态当参数传进去、当结果传出来，造出状态世界。把它与两个现成的世界（第二篇的延续世界、第五篇的列表世界）并排，从复合与单位抽象出单子。回头认出第三篇的 A-翻译对应异常单子：那时是用异常单子模拟异常处理机制，代替了宿主的 `raise`。四个例子之后，结尾是单子难以组合；悬念回到第五篇的做法，那里用定界延续捕获剩余工作，不同的单子都这样做，对应过来就是多条前沿的合并问题，引出第七篇。

〔10/7 稍后 Noah 补充：保留〕v1.2 的一句话里还有两段，第一次口述没有提，Noah 随后说巨大单子是说漏了、要补上，演示完定界延续代替 do 语法后说单子之母：「再回头看 `choose`：shift 捕获的局部延续正是 Kleisli 箭头，于是定界延续能表示这里遇到的每一个单子（单位与连接可用纯函数写出、满足单子律的单子）」，以及「宿主的 let 可以看作一个巨大单子的 do 语法；两个单子同时借用它时，边界认错了人」。这两段就是下文的 §5 与 §6 的前半。

**轴线**
- 明轴（第四篇原话，第五篇已用过）：同一份剩余工作为每个备选各运行一次。第六篇的新东西是把「剩余工作怎样被使用」交给各个世界的连接操作。
- 暗轴一（本文例子里的观察，不是一般分类）：剩余工作被调用至多一次（异常）、恰好一次（v1.3：状态也是恰好一次，另带一份沿途传递的状态）、多次（列表），以及多次调用的结果怎样合并。
- 暗轴二：绑定语法与捕获算子。do 语法在语法层提取局部延续；shift/reset 在运行时提取。落点：§2 第二篇的 `anf:let*` 换掉连接器即得 `for*` 的行为，是可换连接器的 do 语法；§5 shift 在运行时捕获同一个局部延续，do 块逐点改写为外层 `reify`（收单位）、每个绑定处 `reflect`（收连接器）；§6 两段程序并排，兑现；d1：两个单子同时借用同一套定界却出事。
  - 限定：范围只说「这里遇到的每一个单子」或「单位与连接可用纯函数写出、满足单子律的单子」；列表世界要求捕获的延续可多次调用；每个 `reify` 为自己那段计算选定答案类型。
  - 〔假定〕第五篇 §1 已埋下语法这一侧（`let*`、`for*` 用语法构造局部延续，只差调用次数）。
- 逻辑线索（收窄后）：在 reflect / reify 这套表示里，每个 reify 为这段计算选定答案类型 `T q`，怎样使用剩余工作由该单子的连接操作决定。

**单子的读法（Noah，9/24）**：先有一个想要的世界，它有原世界没有的能力；找一个单子，使它的 Kleisli 世界与想要的世界一一对应，就能用单子在原世界里模拟那种能力。
- 带赋值的世界：状态单子，模拟赋值（v1.3 新增，是入口）。〔Claude 草〕`set!` 从第一篇起一直是向宿主借的，这里用纯函数还上，可以接「向宿主借东西」那条线；用不用待 Noah 定。
- 带 `call/cc` 的 𝒞 是想要的世界，延续单子的 𝒦 经 `uncps` 与它对应（需要 `call/cc`，带着第二篇注意框里的两个前提）：模拟延续，也就是经典逻辑。𝒰 经 `flip` 与 𝒦 对应，是纯的另一种写法。
- 能提前返回的世界：异常单子，模拟提前返回（逃逸到边界，第三篇的 `return`），不是 `goto` / `call/cc` 那种去任意位置的跳转；后者归 𝒞。
- 关系世界：列表单子，模拟关系；不是严格一一对应，列表多记了顺序与重数（第五篇已交代〔假定〕）。
- 正文用「世界」「一一对应」「模拟」来说，不说「同构于某范畴」。

**单子的定义方式**：从**类型构造子**出发（9/24 定）。一个类型构造子 T（`Listof`、第二篇的 `¬¬`），加上 `p → T q` 形状箭头的复合与单位，满足单位律、结合律，**并与宿主复合相容**，这一整套就是一个单子。不要求 T 事先能作用在函数上：这种作用由往返一圈自己长出来（§2）。v1.3：状态世界的类型构造子是第三个例子，写法待定。「单子」指整套东西，不是类型构造子本身；「列表单子」指 `Listof` 连同它的复合与单位，第一次命名时说清楚。「函子」一词不出现。

相容律，正文用这个形式（9/24 定）：

```racket
(∘𝒦 f (∘ cps:id h)) = (∘ f h)
```

即「把普通函数用单位抬进新世界，复合方式不变」。它直接接关系框架：普通函数是一种特殊的关系，进了关系世界应当照常复合。三条合起来才构成单子；只写前两条，定义就不对。在单位律、结合律之下，它与 `(∘𝒦 g (∘ f h)) = (∘ (∘𝒦 g f) h)` 等价；原式与等价推导放第二部。

**定律分层与来历（9/24）**：单位律、结合律是**任何世界**都要满足的规则；相容律是**模拟**这件事特有的要求，保证原世界的普通函数在新世界里照常工作。三条都从想要的世界继承：关系的复合满足结合律、有单位（相等关系），普通函数本身是一种特殊的关系；𝒞 的复合同样如此，第二篇的 `∘𝒦` 本来就是照着 𝒞 造的。

**给出定律而不叫「范畴」**：严谨在于论断成立、可检验（三条定律都是代码等式，全部测试通过），不在于给抽象结构起名。〔v1.2：第五篇 §4（v4.3 编号；原 §3）保留四条规则，第六篇回指一次再推广到三个世界；注意不说「从关系世界继承所以逐字成立」〕「世界的规则」第一次说清楚的时刻：原计划在列表世界（第五篇 §3-e「四条规则从关系世界继承」）。若第五篇保留那四条，第六篇回指一次，把它推广到三个世界；若第五篇删去，第六篇在 §2 首次点破：「第二篇起我们一直在说世界，却没说过一个世界得满足什么。以前不需要，现在要亲手造新世界了。」单位不另起名 η，沿用 `cps:id` / `ℒ:id`。

**术语**：正文用「世界」「复合」「单位律」「结合律」「箭头」，不用「范畴」「态射」。「Kleisli」可以用。「计算效应」作为通行说法使用。

### §3 命名：单子，以及想要的世界

- **命名**：一个类型构造子，加上 `p → T q` 形状箭头的复合与单位，满足三条规则，这一整套叫单子；三个世界分别是状态单子、延续单子、列表单子（v1.3；异常单子在 §4 回认）。𝒦 就是 Kleisli，也是第二篇起满眼的 `k`：第二篇随手起的名字，碰巧叫对了一整族世界。命名处写 𝒦 形式的相容律 `(∘𝒦 f (∘ cps:id h)) = (∘ f h)`。
- **想要的世界与模仿它的世界**：带赋值的世界（v1.3）/ 𝒞（经 `uncps`，𝒰 经 `flip` 是纯的另一种写法）/ 关系世界（列表多记顺序与重数）/ 能提前返回的世界（逃逸到边界，不是 `goto`）。

### §6 巨大单子、组合困难与悬念（结尾；原第五篇 §6，v1.2 的 §5）

Noah 10/7：最后是单子组合困难；悬念是回顾第五篇用定界延续捕获，不同的单子对应过来意味着多条 frontier 的合并问题。

- **§6 的顺序（Claude 提，Noah 10/7 认可：「这个顺序很好」）**：
  1. 宿主的 let 是巨大单子的绑定写法。
  2. 那为什么不都用它？因为什么都混在一起，顺序被定死，看类型也看不出用了什么。
  3. 于是想把效应分开，各用各的单子。
  4. 分开以后要合起来用，这就难了。接悬念。
- **为什么不直接用巨大单子**（Noah 10/7）：「还可以说为什么不直接用巨大单子，非要用单子单独处理计算效应。巨大单子意味着各种计算效应混合在一起，经典的一个问题就是后面确定好计算顺序。」
  - 〔Claude 草〕回扣第二篇：第一节就叫「求值顺序与 ANF」，问过两次 `fib` 调用有没有固定顺序，并说「ANF 命名中间值，让求值顺序显式」。`let*` 是巨大单子的绑定写法，每一步都排了序；对纯的计算这个顺序无所谓，有了效应才要紧。
  - 〔Claude 草〕有两种「顺序」，行文要分开：求值顺序（谁先算），是这一条说的；效应之间的层次顺序（谁在里谁在外），是「组合困难」说的。巨大单子把两种都定死了。
  - **可交换**（v1.3.3；Noah 10/7 同意在满足上述条件时进正文）。〔Claude 草，已实测〕它就是「顺序要紧」的准确说法：两步互不依赖，调换先后，结果变不变。状态世界里两次「交出当前的数再加一」，先 `a` 后 `b` 得 `(0 . 1)`，调换后得 `(1 . 0)`。列表世界里调换后是同样的几项，次序不同，正是第五篇说的「列表多记了顺序」。这里的四个例子都不可交换，所以巨大单子要把顺序定死。篇幅：放在四步顺序的第 2 步里，一个小例子加一句话；「可交换」是平常的词，名字要不要进注意框待定。

## 七、第二部素材（原第八篇或后记）：背后的范畴论与 Haskell

- **复合定义单子**：`p → T q` 箭头上的复合满足单位律、结合律，并与宿主复合相容，即得 Kleisli 三元组，与单子等价。最短证明：令 `g* = g ⋆ id`，相容条件给出 `g ⋆ f = g* ∘ f`，再由单位律、结合律得三条 Kleisli 律。只有前两条时未必来自单子（换位构造的反例）。在满足相应参数性原理的纯多态模型中，相容条件可由类型推出；有多态类型语法本身不保证参数性。等式只对纯函数模型成立，带未建模宿主副作用时两种结合方式的调用次序不同。Moggi 的构造直接把复合定义为先计算、再用扩展操作，已包含这种相容。
- **从复合到单子的三层**（9/24 讨论）：
  - 只有范畴公理：η（即各恒等箭头）与 `μ = id_{Ta} ⋆ id_{TTa}` 都写得出，但不一定自然，也不一定满足单子律。反例「搬运结构」：对每个 hom 集合任取双射 Φ，`g ⋆ f = Φ⁻¹(Φg ∘ Φf)` 总是范畴，却与原世界的复合无关。
  - 范畴公理是新世界的陈述；自然性与单子律是原世界的陈述；相容律是桥，使 `g ⋆ f = g* ∘ f`。左单位律 → `η* = id`；右单位律 + 相容 → `f* ∘ η = f`；结合律 + 相容 → `(g* ∘ f)* = g* ∘ f*`。由这三条 Kleisli 律推出：`T′f = (η ∘ f)*` 是函子，η、μ（= `id*`）对 T′ 自然，单子律成立。自然性与单子律共用同一来源。
  - 只需 T 在对象上的映射；若 T 事先是自函子，要它就是所得单子的函子，还需 `T f = (η ∘ f)*`（T = T′）。反例：Set 上 T = Id，`g ⋆ f = g ∘ σ ∘ f`，满足范畴公理与相容律，推出的函子却是共轭 `σ⁻¹ f σ`，η = σ⁻¹ 对恒等函子不自然。代码里「往返一圈 = `neg²` / `map`」就是 T = T′。
  - 相容律的两种形式：`(∘𝒦 g (∘ f h)) = (∘ (∘𝒦 g f) h)` 与 `f ⋆ (η ∘ h) = f ∘ h`，在单位律、结合律下等价。
  - Haskell 以 `return` 加 `>=>` 定义单子只要求范畴律，因为 `>=>` 是多态函数，参数性（自由定理）自动给出相容律；一般的 hom 集合族没有这个约束。我们的 `∘𝒦`、`∘ℒ` 属于前一种。
- **去程与回程是伴随**（按 Noah 的对角线约定：自然变换由它在态射上的作用定义，α(f) = α(b)∘F(f) = G(f)∘α(a)，函子是恒等自然变换）：去程 `cps` 同时是 η 的对角线；回程 `cps->neg²` 同时是 ε 的对角线（ε 在 `f` 上的对角线是 `f ∘𝒦 ε`，读回宿主即 f*，与回程作用在 `f` 上是同一函数；按分量读，ε 的分量是读作 𝒦 箭头的 `values`）；hom 同构是恒等（被类型别名吸收）；UJ = T 即 `flip¹ ∘ flip` 抵消得 `neg²`；μ = UεJ = `(cps->neg² values)`。
- **Kleisli 与已知范畴**：𝒞 ≅ 𝒦（经 `uncps`，需 `call/cc` 及第二篇的前提）；𝒰 ≅ 𝒦（经 `flip`，纯）；Kl(Powerset) ≅ Rel；Kl(Maybe) ≅ 部分函数；有限列表对应像有限的关系。第二部补「Kleisli 范畴」的正式身份。
- **run : E_a → C_a 是单子态射**（sketch 已测单位保持、正常与异常路径、非恒等观察）。**A-翻译那一步 = `(cps->neg² run)`**：`F ↦ λk. F(λv. run v k)`，即延续世界的连接器作用在 run 上（Opus 发现，sketch 已验证）。Astra 的形式化：`run : E_a p → C_a p`，`run* : C_a(E_a p) → C_a p`，A-翻译之后那一步就是 `run*`；传给 `F` 的函数正常分支用 `k`、答案分支取出答案，正是 `[k, id]`。
- **单子之母与 codensity**：固定答案类型时，`m ↦ λk. bind m k` 已是到 `C_{T q}` 的单子态射，取答案为 `T p` 时有还原映射；`∀q. (p → T q) → T q` 解决的是答案类型须事先固定的问题，回指第三篇 `anf:reset` 的 `(∀ (x) …)`。Filinski 定理的适用条件（单位与扩展可用纯函数项表达、控制语义与类型条件）。
- **组合**：分配律（Beck）只是使复合获得单子结构的一种办法。按组合出来的值的形状写，不说「外/内」：
  - 「一个列表，元素要么是结果、要么是错误」：存在，把错误原样放进列表即可（异常叠在任意单子上都成立）。
  - 「要么一个错误，要么一个结果列表」（正常时返回列表、异常时返回错误，连接时遇到异常就传播）：异常值不止一种时结合律失效（Astra 反例），相应的分配律不存在（Zwart & Marsden, No-Go Theorems for Distributive Laws, 例 4.8）。
  - 层次顺序影响语义：Filinski 1999 的具体例子是状态与异常。
- **Haskell**：单子律可用 `>=>` 写成复合律（标准接口以 `>>=` 定义）；Piponi 用 `Cont` 的实现即 reflect / reify；`for*/list` 与列表推导式、Wadler 的 Comprehending Monads。
- **巨大单子的理论背景**：Moggi 的计算 λ 演算；ANF 作为单子范式（Hatcliff & Danvy 1994、Sabry & Felleisen 1993、Sabry & Wadler 1997）。
- **「初始延续」与切片的终对象**：延续 `k : p → R` 是切片 C/R 的对象；初始局部延续 `idᵣ`（即 `values`）是 C/R 的**终对象**。「初始」说的是构造与时间：栈底最先放入、最后执行。前七篇保留「初始延续」。C/R 的初始对象是 `⊥ → R`，即第一篇的 `absurd`。平凡表示下 `a->⊥ᵃ` 与 `⊥ᵃ->a` 都变成 `values`，都是终对象。
- 强单子（v1.3.3）：第六篇正文只给出配对操作与名字。强度要满足的规则、它与「连接器本身是宿主里的函数」的关系、可交换单子的定义，留在这里。
- 延续单子不是自由单子（EM 范畴与 Paré 定理，8/28，未经审阅者核对）；Church / Böhm-Berarducci 编码；自由单子若不进第七篇也放这里。
