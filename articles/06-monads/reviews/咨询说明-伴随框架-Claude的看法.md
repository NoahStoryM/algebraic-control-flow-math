## 1. 成立条件

- **比较定理**（标准结论；Mac Lane 的 Kleisli 构造的泛性质，节号凭记忆）。任给伴随 F ⊣ G，F : 𝒟 → 𝒞，单子 GF 的 Kleisli 范畴到 𝒞 有比较函子 K：对象上 a ↦ F a，箭头上 f : a → GF b 映为 ε ∘ F f。K 总是全忠实，它在 Hom 集上的作用就是伴随的双射。K 是同构，当且仅当 F 在对象上是双射。`inj` 在对象上是恒等，所以只要 `inj` 有右伴随，𝒞 ≅ Kl(T ∘ inj) 就成立。
- **「子范畴」**（推导）。在 Hom 集双射下，`inj f` 对应 η ∘ f，所以 `inj` 忠实当且仅当每个 η 是单的。`inj` 不忠实时宿主不是目标的子范畴，比较同构却照样成立。Set ⊂ Rel 忠实；下面第 4 条的退化情形不忠实。
- **伴随存在是额外的假设**（推导）。框架的两个方向不对称：给定单子，令目标 := Kleisli 范畴，伴随自然存在；给定一个独立描述的「带效应的 𝒞」，T 是否存在是要证的。第二篇属于后一种，见第 2 条。
- 对象上恒等的 J : 𝒟 → 𝒞 正是 Freyd 范畴的形状（Power 与 Robinson 1997）；J 有右伴随的情形对应 Kleisli（Levy、Power、Thielecke 2003 讲闭 Freyd 范畴与强单子的对应）。都凭记忆，未核实。

## 2. 两个 Kleisli

（推导）

- 正文的 𝒦 ≅ 𝒞（数学背景 1.3）是 Kl_𝒞(¬¬) ≅ 𝒞：𝒦 的箭头是宿主 𝒞 里的函数，回程 `uncps` 借 `call/cc`。它说的是「𝒞 里 ¬¬ 可以消去」。
- Noah 的框架要的是 𝒞 ≅ Kl_𝒟(¬¬)：箭头是 𝒟 里纯的 p → ¬¬q。
- 二者之间的缝，正是第二篇注意框的第二个前提：`cps:f` 收到参数时只造出一个等待延续的函数，不做别的事。
- T 作用在一支用了 `call/cc` 的 f 上，要交出一支 𝒟 的箭头 ¬¬p → ¬¬q。宿主里能写出的包装，运行时都要调用 f，f 里的 `call/cc` 照样要靠 𝒞，包装的结果因此不在 𝒟 里（用 prompt 或 Filinski 的 reflect/reify 可以在运行时得到行为对的版本，但它同样用到控制算子）。要得到 𝒟 的箭头，得改写 f 的程序文本，把它整个写成 CPS。所以 T 在 𝒞 的一般箭头上不是 𝒟 里的运行时函数，是程序变换：第三篇的 `anf:` 宏、第四篇的编译器。这一条想请 Astra 一起看。第二篇第 549 行「要让程序本身落在 𝒟 里，每一步都得写成 𝒦 的箭头」说的就是这一点。
- 这给第六篇一条现成的线：T 落实为变换，把第二篇（运行时包装）、第三篇（`anf:` 宏）、第四篇（编译器）串起来。用不用由 Noah 定。

## 3. `neg`、`flip`、`cps`、`neg²`

（推导；与数学背景 1.1、3.5 一致）

- ¬ : 𝒟 → 𝒟ᵒᵖ 与 ¬ : 𝒟ᵒᵖ → 𝒟 伴随，生成的也是 ¬¬。𝒰(p, q) = 𝒟(¬q, ¬p) = 𝒟ᵒᵖ(¬p, ¬q)，即同一个单子经这个伴随写出的 Kleisli 范畴。A8 要的「对偶」就在这里：𝒰 的箭头反向，因为它住在 𝒟ᵒᵖ 里。
- `flip` 是这个伴随的 Hom 集双射 𝒟(p, ¬¬q) ≅ 𝒟(¬q, ¬p)。
- `neg` 第一行 𝒞 → 𝒰：经 𝒞 ≅ 𝒦 ≅ 𝒰，是比较函子，落在 𝒟ᵒᵖ 一侧。
- `neg` 第二行 𝒰 → 𝒟：右伴随 ¬ 作用在箭头上。
- 两行复合是从 Kleisli 回到 𝒟 的遗忘函子，在 Kleisli 箭头 f 上给出 f* = μ ∘ ¬¬f，也就是 Kleisli 扩张，与 3.5 的「回程」一致。
- 代码里的 `neg²` 是 `(λ (kk) (λ (k) (kk (∘ k f))))`，即 ¬¬f，是单子的自函子 T ∘ inj 作用在 f 上。只有 f 纯时它才等于 T(f)；f 用了 `call/cc` 时类型对、程序不对，正是第 547 行那句话。
- 所以 Noah 说「否定翻译是单子的自函子」，对代码里的 `neg²` 成立，签名是 𝒟 → 𝒟；签名 𝒞 → 𝒟 描述的是 T，T 不是这段代码。第三篇已经写成 𝒟 → 𝒟。
- **对应盲读第 5 条**：建议第二篇的签名改成 𝒟 → 𝒟，与第三篇一致；第 547 行那句保留，作为「T 要靠变换」的伏笔。
- **对应盲读第 4 条**（第三篇总结的 `case→`）：`neg` 两行是比较函子与右伴随，方向不同的两种角色；`cps` 只有一行，是 η 的对角线；`flip` 两行互逆，是 Hom 集双射。总结可以按这三种角色区分，不点名。

## 4. ⊥ 为空

（推导；Joyal 引理凭记忆）

- 𝒟 笛卡尔闭、有始对象 0 时，0 是严格的：任何到 0 的箭头都是同构。于是 Hom(x, ¬b) ≅ Hom(x × b, 0) 至多一个元素，¬b 是子终对象，¬¬b = ¬(¬b) 也是。所以 𝒟(a, ¬¬b) 至多一个元素，Kl_𝒟(¬¬) 是预序。
- 若 𝒞 ≅ Kl_𝒟(¬¬)，𝒞 里同类型的两个程序就必然相等，与第二篇的例子矛盾。所以 ⊥ 为空时框架不成立；这时 `inj` 也不忠实（η 不单）。
- 这是 Joyal 引理那一类现象：有始对象的笛卡尔闭范畴里，若每个对象都同构于它的双重否定，这个范畴是预序（Lambek 与 Scott，凭记忆）。
- 第二篇运行时没有退化，是因为 ⊥ 实际由 `raise` 实现（`code.rkt` 的 `a->⊥`），延续最终交给 𝒞 的终结延续，不在 𝒟 里。数学背景 1.1 已记「R 取空集时单子退化」；这里补的是退化对同构的后果：第二篇只能读作「⊥ 是一个抽象的答案类型」，第三篇换成 a 不是可有可无的推广，是框架成立的前提。
- 第三篇「局部否定下的世界」是这轮盲读评价最差的一节，它的动机可以从这里写，不点名：第二篇末尾的缺口（启动 ¬¬a 需要 ¬ 的元素，𝒟 里却造不出来）就是这个现象的程序版。

## 5. 否定翻译与高阶程序

（推导；文献凭记忆）

- T 在对象上只在最外层加 ¬¬。程序的翻译对函数类型要递归：⟦p → q⟧ = ⟦p⟧ → ¬¬⟦q⟧，需要 Kleisli 指数，也就是单子是强的（数学背景 4.1、4.3）。这就是盲读第 24 条说的 Kolmogorov 形状，可以和 1.6 的 Murthy 一起核实后再写。
- A-翻译：T = ¬ₐ¬ₐ，一族以 a 为参数的单子。

## 6. 全不全

（猜测，最想请 Astra 判断）

- 忠实不成问题，全是问题。a 是具体类型时，𝒟 里有 `(λ (k) r)`（不调用延续，直接交出一个答案 r）、`(λ (k) (not (k x)))`（改写答案）这类箭头。前者需要 𝒞 有 abort，第二篇的 𝒞 有 `raise`、`exit`，大概够；后者改写答案，需要定界控制，`shift`/`reset` 的 CPS 正是可以操作答案的那一类。
- 猜测：只有 `call/cc` 时，全性要求答案类型抽象（对 a 参数多态）；a 具体时多出来的箭头，恰是定界控制能写而 `call/cc` 写不出的。若成立，第二篇到第三篇的过渡在框架里就是「目标范畴变大」。第三篇 `anf:reset` 的类型 `(∀ (x) (¬ₓ¬ₓ a))` 已经有答案类型多态的形状。
- Führmann 与 Thielecke 2004 把按值调用的 CPS 变换当作等式理论之间的翻译来研究，有一条加强的完备性结论；它和这里的全性是什么关系，没读原文，不知道。

## 7. 关系一侧

（标准结论；数学背景 2.1、2.2 已记）

- Set ⊂ Rel：`inj` 取图像，T 是幂集，Rel ≅ Kl(P)。程序里是 Kl(P_fin)，有限分支。
- 第五篇用的是列表。Kl(List) 不是 Rel，到有限分支的关系只有一个保持复合、不忠实的「取支撑」。所以第五篇在框架里是「靠上」，不是同构；盲读第 18 条的「不计重复」就是这个差。

## 8. 「代数」

（凭记忆）

- PL 社区说 algebraic effects（Plotkin 与 Power），「代数」指由运算与等式给出的效应；延续通常被列为不属于这一类的例子（Hyland、Levy、Plotkin、Power 2007 讨论代数效应与延续的组合）。单子在范畴论里也连着「代数」（Eilenberg-Moore 代数），但读者未必这样读。
- 若标题的「代数」指这个框架，英文版第一次陈述时值得用一句话划清。第七篇讲代数效应时还要用这个词，`series/threads.md` 里「代数效应」的「代数」指处理者是代数；两处的意思要能对上。
