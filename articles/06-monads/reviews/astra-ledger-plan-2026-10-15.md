1．今天推翻或收紧的条目，以及可替换文本

先统一账本开头的记号。建议直接替换为：

\mathcal D 表示纯计算的基底范畴；讨论内部函数类型时，假设它笛卡尔闭。\mathcal C 表示选定效应及程序等式下的目标范畴，不预设它笛卡尔闭。J=\mathrm{inj}:\mathcal D\to\mathcal C 表示纯程序的纳入；若 J 有右伴随，记为 U:\mathcal C\to\mathcal D，生成的单子记为 M=UJ。答案对象记为 R，真正的始对象记为 0，程序中的 \bot 标注不自动解释为 0。令 N_RX=R^X，延续单子记为 M_RX=R^{R^X}，\mathcal K_R=\mathrm{Kl}_{\mathcal D}(M_R)。原文的 \mathcal U_R 保留为延续变换的另一种表示，勿与右伴随 U 混同。

这是记号约定。特别是：右伴随是 U，单子是 UJ，不能把两者都叫 T。

下面各段均可替换对应条目的“论断”列。

1.1：成立，但必须区分两个伴随，并改掉“非空就够”。【推导】

在纯笛卡尔闭范畴 \mathcal D 中，固定答案对象 R，内部指数 N_RX=R^X 给出函子 N_R:\mathcal D\to\mathcal D^{op}，并有伴随 N_R\dashv N_R^{op}。其 Hom 双射由交换两个参数给出，生成延续单子 M_R=N_R^{op}N_R。令 \mathcal U_R(A,B)=\mathcal D(N_RB,N_RA)，以反向延续变换的复合作为复合，则 flip 给出 \mathcal K_R\cong\mathcal U_R。这不是另一个伴随 J_M:\mathcal D\rightleftarrows\mathcal K_R:U_M 本身。外部函子 \mathcal D(-,R):\mathcal D^{op}\to\mathbf{Set} 与内部指数函子应分开。在 Set 中，R=0 时 M_RX 只区分 X 是否为空，R=1 时一律为单点；两者都不能忠实表示一般纯函数。Set 中 \lvert R\rvert\ge2 才保证延续单子的单位逐分量单射。

最后一句的证明很短：若 x\ne y，取一个 k:X\to R 区分二者，则 \eta_X(x)(k)\ne\eta_X(y)(k)。

1.2：基本成立；把分量、对角线、扩张分别写明。【推导；Kleisli 构造见 Riehl，Lemma 5.2.12】

对纯函数 f:A\to B，cps f 表示 \eta_B\circ f:A\to M_RB，即单位自然变换的对角线，也就是 Kleisli 左伴随在 f 上的作用；单位分量是 cps id。对 g:A\to M_RB，cps->neg² g 是扩张 g^*:M_RA\to M_RB，满足 g^*(m)(k)=m(\lambda a.g(a)(k))。乘法为 \mu_A=(\mathrm{id}_{M_RA})^*，因此代码中的 (cps->neg² values) 必须把 values 读作 \mathrm{id}_{M_RA}。这些是纯模型中的等式；把带宿主效应的函数包进同样的 lambda 外形，不构成消除该效应的翻译。

这里“同一个 values”承担不同类型，是后面通用 let*𝒦 最容易误读的地方。

1.3：原来的普遍同构断言不成立。【推导／反例】

uncps 与运行时 cps 的受限往返等式，不足以推出带控制宿主 \mathcal C 与纯基底上的 \mathcal K_R 同构。要得到该同构，必须先指定语言片段、程序等式及纯编码 E_{A,B}:\mathcal C(A,B)\to\mathcal D(A,M_RB)，证明它保持单位与复合，并证明双向互逆；或者建立对象恒等的伴随 J\dashv U，再证明生成单子 UJ 就是所用的 M_R。收到参数时只构造闭包，是求值时机条件，不是闭包内部纯性的条件。“任何上下文中等价”须改为所选语言片段和观察方式中的等价。另一方面，纯函数模型中的 \mathcal U_R\cong\mathcal K_R 可直接由 flip 证明。

反例仍可用
R=B=\mathbf{Bool},\qquad m(k)=\neg k(\mathrm{false}).
把 m 交给逃逸式 call/cc，调用逃逸延续后，外面的 not 不再执行；因此它不能给出任意纯 m 的逆表示。这否定的是该候选逆，不是所有可能的控制语义表示。

1.8：主要数学内容已经正确，不能再记成“今天推翻”。【推导；历史归属部分未核】

固定 R，异常单子为 E_RX=X+R。本节涉及的中间类型是 M_R(E_RX)=((X+R)\to R)\to R。由余积泛性质，(X+R)\to R\cong(X\to R)\times(R\to R)。从中间类型到 M_RX 的操作是 \theta_X(F)(k)=F([k,\mathrm{id}_R])，即固定答案分支后的特化，不是同构。不同的 F 可以在这一特化下相等；例如 R=\mathbf{Bool}，F_1(k,j)=j(\mathrm{false}) 与 F_2(k,j)=\mathrm{false}。具体程序能作这种特化，须证明所讨论边界的答案分支确实固定为恒等。双延续表示可与 double-barrelled CPS 对照；“整个构造就是 Friedman 的 A-翻译”仍须按所采用的逻辑翻译逐项核实。

双延续的类型分解在 Berdine 等人的 CW’01 文本 §4 可以直接核到；这不能代替 Friedman 原文的核对。

2.2：成立；补上语义模型与程序可定义部分的区别。【推导】

在 Set 的完整语义模型中，\mathcal L=\mathrm{Kl}(\mathrm{List})。取支撑 \mathrm{supp}_X:\mathrm{List}(X)\to\mathcal P_{\mathrm{fin}}(X) 保持单位与扩张，因而诱导保持对象的函子 \mathcal L\to\mathrm{Rel}_{\mathrm{fin}}。该函子不忠实，例如 [b] 与 [b,b] 的支撑相同。若 \mathcal L 指具体语言的程序，则应改为相应的可定义箭头范畴，不能默认包括 Set 中所有函数。

2.3：可以成立，但“有限、纯”不是完整证明。【推导；具体实现仍须证明】

对一阶数据、有限终止、固定枚举次序、无其他可观察效应且允许多次恢复延续的 amb 片段，若 gather 与 scatter 保持单位和复合，并在所选程序等式下双向互逆，则直接风格范畴 \mathcal B 与相应的列表编码范畴同构；对象只在同构意义下对应时，得到等价。等式必须说明观察的是完整有序列表，并适用于声明的程序上下文。这个结论与取支撑后的关系语义不同：后者忘掉次序和重数，不忠实。有限分支本身既不保证整个搜索终止，也不保证给定关系可计算枚举。

3.5：按“对角线”约定成立，需要补类型。【推导】

在 Kleisli 伴随 J_M\dashv U_M 中，J_Mf 由单位的对角线 \eta_B\circ f 表示。余单位分量 \varepsilon_B:MB\to_{\mathcal K}B 由纯箭头 \mathrm{id}_{MB} 表示。对 h:A\to_{\mathcal K}B，余单位的对角线为 h\circ_{\mathcal K}\varepsilon_A=\varepsilon_B\circ_{\mathcal K}J_MU_Mh；将这支 Kleisli 箭头读回基底，得到 h^*:MA\to MB，也就是 U_Mh。因此，“扩张是余单位的对角线”在这个表示约定下正确；扩张不是余单位分量本身。乘法仍为 \mu=U_M\varepsilon J_M。

确切核算是
\underbrace{h\circ_{\mathcal K}\varepsilon_A}_{MA\to_{\mathcal K}B}
\quad\text{由}\quad
h^*\circ\mathrm{id}_{MA}=h^*
\quad\text{表示。}

我前面若将“扩张是余单位的对角线”一概否定，也应收回。不能把对分量读法的纠正，施加到你们已经说明的对角线读法上。

3.8：前半成立，后半需要自然性、存在性及非同构限定。【推导】

对 Set 上的单子 M，固定对象 Q，映射 \iota_A^Q(m)(k)=k^*(m) 给出单子态射 M\to M_{MQ}，其中右侧是答案对象为 MQ 的延续单子。它不一定单射，例如 M=\mathrm{Id},Q=1。若相应的右 Kan 扩张存在，codensity 单子写为 \mathrm{Cod}(M)A=\int_Q\mathbf{Set}(A,MQ)\to MQ；其中的族必须对 Q 自然，不能解释为不受约束的任意族。上述映射组成 M\to\mathrm{Cod}(M)，且在对象 A 处可由 \Phi\mapsto\Phi_A(\eta_A) 还原 M A 中的元素。因此得到逐分量单射，但一般不是同构。在一般笛卡尔闭基底中，将这些公式解释为内部箭头还需要适当的强度／内部扩张。

这里的还原只说明
\iota_A(m)_A(\eta_A)=\eta_A^*(m)=m.
它不说明每个 codensity 元素都来自 M A。

9.3：需要实质改写。【定理：米田引理；具体辨别为推导】

米田引理给出 \mathrm{Nat}(\mathbf{Set}(A,-),\mathrm{Id})\cong A，对应在 A 处代入 \mathrm{id}_A。将其写成 \forall R.(A\to R)\to R\cong A，须要求该多态族满足适当的自然性／参数性；仅有量词或答案类型可改变不够。固定答案对象时，没有这一还原定理，也不能无条件说 M_RA 比 A 大。操作 m\mapsto m(\mathrm{id}_R):M_RR\to R 是在特定对象 R 上运行计算，满足 \mathrm{eval}_R\eta_R=\mathrm{id}_R，一般不满足反向等式。因而第二、三篇的 eval 和答案类型可变的 reset，不能仅凭“传入恒等”就判作米田同构的实例。

直接证明：自然性令 a=\Phi_A(\mathrm{id}_A)，便有
\Phi_R(k)=k(a).
固定 R 时恰恰缺少跨对象的这一步。

9.5：只能保留为待逐对建立的对应。【推导；部分未核】

scatter／gather 在受限列表效应模型中可分别实现 reflection／reification；其往返条件见 2.3。运行时 uncps／cps 只有在另行证明的控制语义和程序等式下才可作类似解释，不能自动等同于纯 CPS 编译及其逆。anf0／anf1 的对应须依据具体定义、输入输出语言与正确性定理单独核对。共同的“直接风格与显式编码之间搬运”意图，不等于三对操作具有相同的类型、实现层次或往返定理。

3.2 的第一个反例可以完全具体化。取只有一个对象、箭头群为 \mathbb Z/4\mathbb Z 的范畴。令 \Phi 交换 1,2，固定 0,3。搬运后的复合满足范畴公理，但

f\circ h=f\star(\eta\circ h),
g\star(f\circ h)

由此再得 g\star f=g^*\circ f，不需要把完整相容律偷偷当作前提。

3.9 的结合律反例。令错误 a\ne b，采用“正常列表逐项连接，出现错误立即传播”的候选操作。取
m=\mathrm{Ok}[0,1],\quad
f(0)=\mathrm{Ok}[()],\quad f(1)=\mathrm{Err}(a),\quad

则
\[
(m\bind f)\bind g=\mathrm{Err}(a),\qquad
m\bind(\lambda x.f(x)\bind g)=\mathrm{Err}(b).

第 4 组

4.1：要改。“闭包能当箭头，靠强度”不够准确。【推导】

可替换为：

普通单子的扩张处理 f:A\to MB。有自由变量环境 \Gamma 时，一步计算是 f:\Gamma\times A\to MB，顺序绑定需要把它扩张成 \Gamma\times MA\to MB。强度提供这种保留环境的扩张，公式为 f^\dagger=\mu_B\circ Mf\circ t_{\Gamma,A}。因此，强度支持的是含自由环境的顺序组合，不是一般地“让 lambda 成为箭头”。环境为空时，普通扩张已经足够；对函数值本身的高阶解释，还须考虑内部函数对象。

这正是 McDermott–Uustalu 论文引言中区分普通扩张与强扩张的方式。

4.2：公式成立；原有前提不足以覆盖一般 CCC。【推导；定理出处如下】

可替换为：

在 Set 中，或在具有内部扩张 (MB)^A\to(MB)^{MA} 且内部单子律成立的笛卡尔闭模型中，配对操作 \(t_{A,B}(a,m)=m\bind(\lambda b.\eta(a,b))\) 给出强度。一般范畴上的外部扩张函数 \mathcal D(A,MB)\to\mathcal D(MA,MB) 不自动给出这个内部操作；“对类型参数多态”若未附相应语义，也不能补足此缺口。强度必须满足自然性，以及与终对象、乘积结合、单位、乘法的相容条件。

忽略乘积的规范同构，四个结构条件是
t_{1,B}=\mathrm{id},
\qquad
t_{A\times B,C}
=t_{A,B\times C}\circ(\mathrm{id}_A\times t_{B,C}),
t_{A,B}\circ(\mathrm{id}_A\times\eta_B)=\eta_{A\times B},
t_{A,B}\circ(\mathrm{id}_A\times\mu_B)
=\mu_{A\times B}\circ M(t_{A,B})\circ t_{A,MB}.
自然性不能漏掉。内部扩张与强单子的对应可引 McDermott–Uustalu，Def. 5.6、Prop. 5.8。

4.3：前半成立；“这些语言里会失败”应删除。【定理＋推导】

可替换为：

Set 上每个单子都有唯一的、相对于笛卡尔积的典范强度。一般 CCC 上强度是额外结构，可能不存在，也可能不唯一；仅有内部函数类型不够。内部扩张及其内部定律足以提供强度。不能仅凭“一阶”“线性”或“分阶段”这些语言标签判断强度不存在；这些语言可能使用不同的环境结构及相应强度。Moggi 的强单子框架针对的是具有相应环境和顺序绑定结构的计算语言。

出处要精确分工：Moggi 1991 Prop. 3.4 是有足够点时的唯一性判据，不是所有 CCC 上的存在性定理；Set 的唯一存在性可引 McDermott–Uustalu，Prop. 3.6、Ex. 3.7。

4.4：在 Set 的这些标准单子上成立。【推导】

可替换为：

对带指定强度的单子，可交换性要求对所有独立计算 m:MA,n:MB，先运行 m 再运行 n 与反向运行、但仍按 (a,b) 排列结果的两种计算相等。在 Set 的典范强度下：状态集至少有两个元素时，状态单子不可交换；答案集至少有两个元素时，延续单子不可交换；至少有两种异常时，异常单子不可交换，而 Maybe 可交换；列表单子不可交换，多重集单子可交换。判断必须声明观察是否保留次序、重数及最终状态。

延续的反例甚至不需要调用延续：在 M_R1 中取
m(k)=r_0,\qquad n(k)=r_1,\qquad r_0\ne r_1.
两种运行顺序分别得到 r_0,r_1。异常也用两个不同错误即可。

因此大纲“四个例子都不可交换”只能在这些非退化条件下写。

4.5：成立；再收紧“层次顺序”这个说法。【推导】

可替换为：

求值顺序由语言及其语义翻译选择；单子提供有顺序的组合操作，本身不替源语言选择实参求值次序。不同效应的组合还须指定交互语义，例如异常后保留还是丢弃状态。这种交互常可由不同的分层表示，但不存在一个对所有效应统一适用的“交换两层即可组合”的规则。两步计算能否交换，与两个效应如何组合，是不同问题。

状态／异常的具体分层差异可直接引 Filinski 1999 §2.4。

4.6：前半可核；最后一句不成立。【规范核对＋推导】

建议替换为：

不同语言对求值顺序的规定不同。例如 C11 的一般函数实参没有固定的左右次序；当前 C++ 工作草案也不固定不同参数初始化的先后，但要求它们之间具有 indeterminately sequenced 的关系。R7RS Scheme §4.1.3 和 OCaml 5.3 手册的函数应用规则不指定实参求值次序；Racket 的函数应用按从左到右求值。惰性求值不等于效应时机“不可预测”：须具体说明需求求值规则、效应接口及其排序保证。

出处分别已核到 C11 N1570 §6.5.2.2、C++ [expr.call]、Scheme、OCaml 与 Racket 的官方文本。

另外，“有效应时编译器不能重排、合并、并行”也太强。正确说法是：这些变换必须保持可观察行为，不能无条件使用纯计算中的等式。

第 9 组

9.1：初始代数部分成立；“任何结构递归恰好是一个 foldr”过强。【推导】

可替换为：

在 Set 中，有限列表是 F_A(X)=1+A\times X 的初始代数。给定代数 z:1\to B,h:A\times B\to B，存在唯一函数满足 f([])=z、f(a::xs)=h(a,f(xs))，即相应的 foldr。map 和纯、总的 append-map 满足所列折叠公式。需要同时访问原尾列表与递归结果的结构递归，不一定直接是保持原返回类型的 foldr；可借助更大的累积类型表示。变参 Kleisli 复合是对可衔接箭头链的折叠，通常不是一个同质类型 List(A→MA) 上的普通列表折叠。

反例：规定 tail []=[]。若 tail=foldr h []，由 tail [x]=[] 得 h(x,[])=[]。于是
\mathrm{tail}[x,y]=h(x,h(y,[]))=[],
却应当是 [y]。

还有一个操作语义限定：在严格求值语言里，所写 foldr 版本可能改变 f 的调用顺序；纯、总时的外延相等不能直接推广到有效应的 f。

9.2：数学对应可保留；实现断言本次未复核。【推导／代码未核】

3．账本缺少的论断：建议新增的表格行

以下按要求只列“论断、核对”，不编号。

论断	核对
设 J:\mathcal D\to\mathcal C\dashv U，M=UJ。比较函子 K:\mathrm{Kl}(M)\to\mathcal C 定义为 KA=JA、Kf=\varepsilon_{JB}\circ Jf。伴随 Hom 双射使 K 全忠实。若 J 在对象上恒等，则 K 是同构；若 J 本质满，则 K 是等价。此结论不需要 CCC、强度或 J 忠实。	定理／推导。标准比较构造见 Riehl §5.2，Prop. 5.2.13；本行的全忠实与对象条件由伴随双射直接推出。
在上述伴随中，J 忠实当且仅当每个单位分量 \eta_B:B\to MB 为单态。因为 Jf 的转置为 \eta_B\circ f，故 Jf=Jg\iff\eta_Bf=\eta_Bg。	推导。
“纯程序嵌入”若意指保留区别，应要求忠实，而非全忠实。左伴随 J 若全忠实，则 \eta 为同构，M\cong\mathrm{Id}；再加对象恒等，便没有新增同型箭头可表示额外效应。	推导，由伴随单位判据。
对象恒等且忠实的 J 不保证右伴随存在。取 \mathcal D=\mathrm{FinSet}，\mathcal C 为有限集合与自然数值矩阵，以矩阵乘法复合，J 把函数送到其 0/1 矩阵。则 \mathcal C(1,1)\cong\mathbb N，不可能同构于任何 \mathrm{FinSet}(1,U1)。	推导／反例。
J 有右伴随的实质条件是各预层 \mathcal C(J-,B) 可表示，并能组成所需的伴随；“给每个效应程序加一个外包装”不证明这种可表示性。	定理的标准表述／推导。
对象恒等时，伴随编码为 E(f)=U(f)\circ\eta_A:A\to MB，而右伴随在箭头上的作用为 U(f)=\mu_B\circ M(E(f))=(E(f))^*:MA\to MB。编译到显式效应表示首先对应 E，不是直接对应 U。	推导，由自然性及三角恒等式。
CCC 若有始对象 0，则 0 严格且为次终对象；因而 0^X 与 0^{0^X} 都是次终对象，\mathrm{Kl}(M_0) 是薄范畴。在非薄的纯基底上，其纯纳入不可能忠实。这不否定否定伴随或延续单子的存在。	推导。
强度 A\times MB\to M(A\times B) 与 M-指数 (MB)^A 是不同结构。前者支持保留环境的组合，后者支持效应函数的高阶值表示；CCC 保证后一种对象存在，不自动保证前者。Kleisli 范畴也不因此自动笛卡尔闭。	定理／推导。Moggi 1991 Def. 3.2、Def. 3.9；Führmann 1999 §5.1.3。
对象恒等的 Kleisli 伴随中，要求每个 \eta_A 是 \eta_{MA},M\eta_A:MA\rightrightarrows MMA 的等化子，等价于 J 忠实且目标中的每个 thunkable 箭头都在 J 的像里。这是内部识别整个纯基底的条件，不是比较同构的必要条件；thunkable 是该模型中的技术定义，不能直接换成源码“不含效应”。	定理：Führmann 1999 Def. 5.22、Thm. 5.23、Lemmas 5.26–5.27。
高阶按值翻译须同时翻译值类型：典型地 V(A\to B)=V(A)\to M(V(B))，计算类型为 M(V(A))。因此“把每个原类型外面套一层 M”不足以给出完整高阶 CPS／单子翻译；对象恒等应在选定的语义对象及类型解释之后理解。	推导；Moggi 的计算函数空间框架、Filinski 1999 §2.3 的类型翻译。
程序模型中的“全部箭头”通常指可定义项模去选定等式，不能默认等于 Set 中全部函数。语法翻译的满性、语义 Hom 集的满性、观察等价的充分必要性，是不同命题，需分别证明。	推导。例如可数语法不能定义某些不可数 Hom 集中的全部函数。
通用绑定中的 \mathrm{id}_{MA}:MA\to MA，读作 Kleisli 箭头时是 \varepsilon_A:MA\to_{\mathcal K}A，不是对象 A 的 Kleisli 恒等 \eta_A。因此 (g\star\mathrm{id}_{MA})(m)=g^*(m)；这个重读就是通用 let*𝒦 中 id 的作用。	推导。
用 A\cup\mathrm{Ans}(R)、单位为原样返回、遇 Ans 就传播的表示，只在结果类型不与 Ans 重叠的片段中实现异常连接。该类型范围不对异常构造封闭，不能据此定义全类型上的异常单子。一般异常单子使用真正的不相交和 A+R，允许区分“正常返回一个异常值”与“当前计算抛异常”。	推导／反例，详见第五项。

比较构造的文献支持见 Riehl；Führmann 的等化子条件和对应定理这次重新核到了原文。

这里最值得保留的一条逻辑顺序是：
\text{先证明 }J\dashv U
\quad\Longrightarrow\quad
\text{得到 }M=UJ
\quad\Longrightarrow\quad
\text{用对象条件识别 }\mathcal C.
“目标与 Kleisli 同构”不能反过来替尚未建立的伴随提供证据。

5．其他遗漏

第一，异常表示的闭包性问题应当单独入账。【推导】

设代码用
E_{\mathrm{raw}}A=A\cup\mathrm{Ans}(R),
单位是原样返回，扩张一见 Ans 就传播。

当 A 不含 Ans 时，这能正确实现该层的异常连接。但若要成为单子，就必须也允许 E_{\mathrm{raw}}A 作为输入对象。取
f:E_{\mathrm{raw}}A\to E_{\mathrm{raw}}B
为一个忽略输入、恒返回普通值 b 的函数。对 e=\mathrm{Ans}(r)，有
(f^*\circ\eta_{E_{\mathrm{raw}}A})(e)=e
\ne b=f(e).
单位律失败。

第二，单位、余单位和运行器不能靠同一个函数名互认。【推导】

账本至少应随出现位置标出这四种类型：

\eta_A:A\to MA,\qquad
\varepsilon_A:MA\to_{\mathcal K}A,\qquad
\mu_A:MMA\to MA,\qquad
\mathrm{eval}_R:M_RR\to R.

即使代码里若干位置都出现 values 或 id，也不是同一支数学箭头。尤其：

* 通用 let*𝒦 的 id 是余单位的基底表示；
* cps id 才是 Kleisli 恒等的基底表示；
* 向计算传入恒等得到的 eval，不是一般的余单位分量。
