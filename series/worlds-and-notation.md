# 世界与记号

这一页收着各篇共用的记号：有哪些世界，箭头怎样在它们之间搬运，每个世界的复合与绑定写法，以及命名的约定。第三、四篇的记号（局部否定 `¬ᵣ`、答案类型等）要等拿到正文再补。

## 世界一览

> 10/30 起 𝒞、𝒟 互换名字（Noah 定）：𝒞 取 constructive，是纯的宿主；𝒟 取 direct style，是带 `call/cc` 的宿主。本文件已照换；10/30 以前的讨论与审稿记录仍是旧名（𝒟 纯、𝒞 带 `call/cc`），读时注意。

一个世界由箭头的类型与复合决定。带能力的宿主（𝒟、ℬ）是想要的世界，纯宿主 𝒞 里造出来的（𝒦、ℒ）是模拟它的世界。

| 世界 | 是什么 | 箭头 `p → q` 的类型 | 复合 | 出场 |
| --- | --- | --- | --- | --- |
| 𝒞 | 纯的宿主，直觉主义 | `p → q` | `∘` | 第二篇 |
| 𝒟 | 𝒞 加 `call/cc`，经典 | `p → q` | `∘` | 第二篇 |
| 𝒦 | CPS 世界，在 𝒞 里模拟 𝒟 | `p → ¬¬q` | `∘𝒦` | 第二篇 |
| 𝒰 | 逆否世界，𝒦 的另一种写法 | `¬q → ¬p`，写作 `¬p ← ¬q` | `∘𝒰`，即顺序反过来的 `∘` | 第二篇 |
| ℬ | 𝒞 加 `amb`；函数就是二元关系 | `p → q` | `∘ℬ`，就是 `∘` | 第五篇 08 |
| ℒ | 交出列表的函数，在 𝒞 里模拟 ℬ | `p → (Listof q)` | `∘ℒ`，即 `(foldr append-map (list x) f*)` | 第五篇 08 |
| ℛ | 关系语言的世界：箭头是两个位置的关系 | 关系 `(P x y)`，交出一个目标 | `∘ᵒ`，用 `fresh` 与合取定义 | 第五篇，未写 |
| 异常世界 | 能提前返回 | `p → (∪ q (Ans a))` | `∘E` | 第六篇的计划 |

- 𝒟、𝒦、𝒰 同构，是同一个世界的三种写法；回到 𝒟 要用 `call/cc`，并带着第二篇注意框里的两个前提。
- ℬ 与 ℒ 同构，都是对二元关系的模拟；列表多记了结果的先后与重复。只讨论纯的、有限的搜索。
- **旧名**：第五篇早期的文件里 𝒮 指普通函数的世界，ℛ 指使用 `amb` 的世界。10/5 起 `amb` 的世界叫 ℬ，ℛ 改指关系语言的世界。第六篇的大纲还是旧名。

## 搬运

搬运是把一个世界的箭头变成另一个世界的箭头的函数。第二篇的四个世界画成一张图（文中原图），方括号标出逆运算：

```
 𝒞 ───inj────→ 𝒟 ←───────────┐
 ↑             ↑             │
 │             │             │
 │          [un]neg       [un]cps
 │             │             │
 │             ↓             ↓
 └────neg¹──── 𝒰 ←─flip[¹]─→ 𝒦
```

| 搬运 | 从 | 到 | 定义 | 说明 |
| --- | --- | --- | --- | --- |
| `inj` | 𝒞 | 𝒟，第五篇里也用于 𝒞 到 ℬ | `(define (inj f) f)` | 纯函数原样进入带能力的宿主 |
| `neg` | 𝒟 | 𝒰 | `(define ((neg f) kq) (∘ kq f))` | 把 `f` 接到延续前面 |
| `cps` | 𝒟 | 𝒦 | `(∘ flip neg)` |  |
| `flip`、`flip¹` | 𝒰 | 𝒦，反向是 `flip¹` | 交换两层参数 | 互逆，纯 |
| `uncps` | 𝒦 | 𝒟 | `(define (uncps cps:f) (∘ call/cc cps:f))` | 要用 `call/cc` |
| `unneg` | 𝒰 | 𝒟 | `(∘ uncps flip)` |  |
| `neg¹` | 𝒰 | 𝒞 | 就是 `neg`，用在高一层 | 节点从 `p` 变成 `¬¬p` |
| `neg²` | 𝒟 | 𝒞 | `(∘ neg¹ neg)` | 只翻译箭头的类型 |
| `cps->neg²` | 𝒦 | 𝒞 | `(∘ neg¹ flip¹)` | 𝒦 的箭头 `p → ¬¬q` 变成 `¬¬p → ¬¬q`；`anf:let*` 靠它连接 |
| `scatter` | ℒ | ℬ | `(define (scatter f) (∘ list->amb f))` | 把列表散成几条时间线 |
| `gather` | ℬ | ℒ | `(define ((gather g) . x*) (in-amb (apply g x*)))` | 把各条时间线的结果收成列表 |
| `function->relation` | ℬ | ℛ | 未定稿 | 结果排在最后一个位置 |
| `predicate->relation` | 谓词 | ℛ | 未定稿 |  |
| `relation->function` | ℛ | ℬ | 只有原型 |  |

第五篇计划在 ℛ 一节画 ℬ、ℒ、ℛ 三个世界的交换图，结论里添上 𝒞 成四个世界，与第二篇的图对照。

## 绑定的写法与复合

每个世界都有一种绑定的写法，写出来的就是这个世界的复合，多出来的只是中间结果的名字。这是第二篇（10/6 修订）与第五篇共用的一条线，第六篇要接着它讲。

```racket
(let*      ([y     (f x)] [z     (g y)])         z)   =  ((∘      g     f) x)     ; 𝒟，第二篇
(anf:let*  ([y (cps:f x)] [z (cps:g y)]) (cps:id z))  =  ((∘𝒦 cps:g cps:f) x)     ; 𝒦，第二篇
(let*      ([y (f x)] [z (g y)]) z)                   =  ((∘ℬ g f) x)             ; ℬ，第五篇 08
(for*/list ([y (f x)] [z (g y)]) z)                   =  ((∘ℒ g f) x)             ; ℒ，第五篇 08
(fresh (y) (P x y) (Q y z))                           =  ((∘ᵒ Q P) x z)           ; ℛ，第五篇，未写
```

单个绑定拆开以后，差别只在「等着结果的那个 λ 怎样接到前一步上」：

```racket
(let       ([v e])  b)  =  ((λ (v) b) e)                    ; 宿主：直接调用
(anf:let*  ([v e])  b)  =  ((cps->neg² (λ (v) b)) e)        ; 𝒦：补一个 cps->neg²
(for*/list ([v e*]) b)  =  (append-map (λ (v) (list b)) e*)  ; ℒ：对每一项各调用一次，再接起来
```

- 两步的复合化简到底，第二篇是 `(neg²:g (cps:f x))`，第五篇是 `(append-map g (f x))`，是同一个式子的两个实例：`cps->neg²` 对「把 `g` 交给 `append-map`」，`cps:id` 对 `list`。
- `for*/list` 的循环体只写 `z`，包成列表的那一步由语法代劳；`anf:let*` 要自己写 `(cps:id z)`。
- 两个模拟的世界，复合都是先绕道另一个世界定义、再化简：`∘𝒦` 经 𝒰，`∘ℒ` 经 ℬ。
- 与第五篇 07 的表接上：复合是遮住中间一列，绑定的写法是给中间那一列起名字。

每一行都在代码里核对过，`fresh` 那一行除外，它只在原型里跑过。

## 命名与排印的约定

| 记法 | 意思 | 例子 |
| --- | --- | --- |
| 前缀 `cps:`、`neg:`、`neg²:` | 这支箭头住在哪个世界、是哪种写法 | `cps:f` 是 𝒦 的箭头，`neg:f` 是 `(flip¹ cps:f)`，`neg²:g` 是 `(cps->neg² cps:g)` |
| 前缀 `anf:` | 嵌入语言的宏 | `anf:let*`、`anf:if`、`anf:let/cc`、`anf:eval` |
| 上标 `¹`、`²` | 同一段代码用在另一个方向或高一层；两次 | `flip¹`、`neg¹`、`neg²` |
| 世界的下标 | 那个世界的箭头类型与复合 | `→𝒦`、`∘𝒦`、`→ℒ`、`∘ℒ`、`¬𝒦` |
| 上标 `ᵒ`（及 `ᵉ`、`ᵘ`） | 关系，照《The Reasoned Schemer》的排印 | `betweenᵒ`、`pythᵒ`、`∘ᵒ`、`condᵉ`；相等写 `≡` |
| `¬`、`¬¬`、`⊥`、`←` | 否定 `(→ a ... ⊥)`（不限参数个数，Noah 10/30 晚；`→𝒦`、`→𝒰` 等同样写成 `p ... q`）、双重否定、空类型、反着写的箭头 | `(define-type (← q p) (→ p q))` |
| `a->⊥`、`⊥->a` | 初始延续（抛出答案）与接住答案的边界 | `(⊥->a (fact/k 5 a->⊥))` |
| `k`、`kq`、`kp`、`kk` | 延续；`kp` 是收 `p` 的延续，它收到的值就叫 `p`；`kk` 是 `¬¬` 类型的值 | `(kp p)`、`kkv` |
| 后缀 `*` | 列表或变参 | `v*`、`f*`、`p*` |
| `amb`、`for/amb`、`for*/amb`、`in-amb` | 第五篇的不确定运算，名字照 Noah 的 amb 库 | `(in-amb (amb 1 2 3))` |
| `choose/k`、`choose` | 第五篇推导里的两个名字：带延续参数的与擦掉以后的 | `list->amb` 与 `choose` 是同一个函数 |

**搬运的类型怎么写**（Noah 10/5）：一个搬运 F 按它作用在箭头上的样子来声明类型。

```racket
(: F (∀ (a b) (→ (→𝒟 a b) (→𝒞 (F a) (F b)))))
```

两个搬运之间的变换写成自然性方块的对角线，类型是 `(→ (→𝒟 a b) (→𝒞 (F a) (G b)))`；所以 `cps` 可以读作单位本身。变参复合的类型写成 `(∀ (p ...) (→ (→𝒦 pn-1 pn) ... (→𝒦 p1 p2) (→𝒦 p1 pn)))`。
