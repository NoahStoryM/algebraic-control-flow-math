### A-翻译与两个延续

第三篇 A-翻译一节背后的推导：翻译后的计算要两个延续，其中一个不变，可以省掉。Claude 10/7 按定义推出，没有查文献；Noah 说与他印象里的一致。

1. **异常单子**：带答案路径的结果是 p + a，提前返回就是走右边那一支。这是第三篇开头 `ans` 版的 `mul`。
2. **两种翻译叠起来**：否定翻译给出 (p → ⊥) → ⊥；再做 A-翻译，p 变成 p + a，⊥ 变成 a，得到 ((p + a) → a) → a。
3. **copairing**：一个 (p + a) → a 的函数等价于一对函数 \[k, j\]。k : p → a 处理普通值，是当前局部延续；j : a → a 处理提前到来的答案。所以翻译后的计算要的是两个延续。
4. **省掉一个**：在一段局部计算里，k 每走一步都在变，j 从头到尾不变，它就是初始局部延续，平凡表示下是恒等。不变的东西不必当参数传，拿出来当全局的，计算就只等一个 k，类型成了 (p → a) → a，即 ¬ₐ¬ₐp。
5. **提前返回**：不调用 k，把答案直接交给被省掉的 j。这就是 `cps*` 与 `cps:abort`。

正文里的 `(λ (v) (if (ans? v) v (k v)))` 正是 j 取恒等时的 copairing \[k, id\]，也是下表最后一行那个 `run`：`run e k = [k, id] e`。带两个延续的 CPS 在文献里叫 double-barrelled CPS，印象中出自 Thielecke；这是 Claude 凭记忆说的，没有核实。

由此记下第三篇两处候选的小改，Noah 10/7 都还没有决定：

- **A-翻译一节**：第 3、4 步是整节的关键，正文各只有一句话。把「要两个延续，其中一个不变」明说出来，配一小段能跑的代码。Noah 自己也觉得第三篇末尾写得赶。
- **「局部否定下的世界」的下标**：带两个下标的局部否定只出现在这一节的八九行里，第四、五篇没有再用。候选改法是不缩写，写成 `(→𝒦ₐ p ⊥ᵃ)` 与 `(→𝒦ₐ p ⊥)`，两个运算符的差别只剩一个上标，两个视角靠 `⊥ᵃ = a` 保住。Noah 引入这个记号的动机是强调局部延续就是普通函数，也强调视角（有时当局部延续用，有时当普通函数用）；他担心去掉会丢掉这一点，也在想慢文章细读也许问题不大。几个 AI 审稿时都指出过下标过密。检验办法：问一两个读过第三篇的人，或者放两周再自测。

## 单子（第六篇与第二部）

- **用复合定义单子**：`p → T q` 形状的箭头上的复合满足单位律、结合律，并与宿主的复合相容，即得 Kleisli 三元组，与单子等价。只有前两条时未必来自单子，有反例。
- **去程与回程是伴随**：去程 `cps` 同时是 η 的对角线，回程 `cps->neg²` 同时是 ε 的对角线。
- **单子之母与 codensity**：定界延续能表示的是「单位与扩张可用纯函数写出、满足单子律」的单子（Filinski 定理的适用条件），正文不写「任意单子」。
- **组合**：分配律（Beck）只是使复合获得单子结构的一种办法；「要么一个错误，要么一个结果列表」在异常值不止一种时结合律失效（Astra 的反例已实测；Zwart 与 Marsden 例 4.8）。
- **巨大单子**：Moggi 的计算 λ 演算；ANF 作为单子范式（Hatcliff 与 Danvy 1994，Sabry 与 Felleisen 1993，Sabry 与 Wadler 1997）。
